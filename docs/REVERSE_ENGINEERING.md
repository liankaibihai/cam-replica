## 2. 拆成六个模块

1. **数据层**：旧 MAT 白名单导入；自有项目 schema；保留旧控制点和权重作参考，但不自动沿用其未确认含义。
2. **路线层**：前轮轨迹的独立三次插值样条；发车航向作为首端切线约束。
3. **运动学层**：由前轮轨迹积分车身航向，求后轮、传感器、前轮转角及主动轮行程。
4. **凸轮层**：机构位移律，行程到凸轮相位，接触滚子圆包络；补全剩余角度的回程。
5. **优化层**：明确归一化的几何目标；有限差分梯度和回溯；固定起点，保存最优状态；不是原版算法的逆向源码。
6. **应用层**：中文参数/点表、绘图、运行/停止、项目保存、坐标导出。

## 3. 数学定义

前轮轨迹 F(u)=(x(u),y(u))，车身航向 ψ，轴距 L=-driving_y。车身前向 f=(cosψ,sinψ)，右向 r=(sinψ,-cosψ)。后轴与车身纵轴交点 P=F-Lf，不要求 P 恰好是两个后轮的中点。

由后轮无侧滑约束得到：

```
dψ/du = (-x'(u)sinψ + y'(u)cosψ) / L
δ = wrapToPi(atan2(y',x') - ψ)
ds_drive/du = x'cosψ + y'sinψ + driving_x*dψ/du
S = F + sensor_x*r + sensor_y*f
```

禁止主动轮行程倒退、奇异前轮转角。轮径 D，总传动比 i 约定为“主动轮转数 / 凸轮转数”：

```
φ = 2*s_drive/(D*i)
h = c*tanδ    平推
h = c*δ       齿条
q = d/2 + h
pitch = q*[cosφ, sinφ]
actual = pitch - rollerRadius*outwardNormal(pitch)
pressureAngle = atan(abs(dq/dφ)/q)
```

φ 是在凸轮固连坐标中接触中心的相位，按该定义装配时凸轮实际转动为 -φ，固定推杆在 +X 方向。真实旋向与零位尚待原软件/实物对照。

工作段结束到 2π 使用匹配两端位移、一阶和二阶导数的五次回程。回程不参与比赛路线，但参与闭合凸轮的几何校验。总传动比过小时，可明确启用自动增大传动比；导出记录必须给出实际使用的传动比。

检查正半径、压力角、曲率包络局部欠切、闭合轮廓交叉、前轮转角、路线有序打卡误差。上述是离散几何校验，不能替代接触动力学/磨损/加工/实车验证。

反推仿真从工作段 `φ,q` 恢复 δ，以主动轮行程为自变量独立积分车身位姿。它不使用实际轮廓重建滚子接触，因此不应称为制造误差仿真。

v0.2 增加固定理论凸轮的试调模式：设计后冻结 `φ,q`，使用试调车体参数重新积分；物理传动比可独立指定，`s=φ*D_actual*i_actual/2`。轮径、齿轮半径、中心距、轴距、发车方向和传感器位置变化作用于反推过程，不能先重新算一个适应该参数的新凸轮。退出模式恢复设计状态。

## 4. 原 MAT 字段

| 原字段 | 本版本用途 |
|---|---|
| `pathway_points` | 按顺序的传感器目标点；第一点作为发车时传感器位置 |
| `driving_x/y`, `driven_x/y` | 后轮位置，验证两后轮 Y 相同 |
| `sensor_x/y`, `vc_x/y` | 传感器位置、初始车身方向 |
| `dh`, `i_total`, `c`, `r`, `d`, `f` | 轮径、轮/凸轮传动比、转向偏距、推杆接触曲面半径、基准中心距两倍、厚度（本版仅保留；原版仅斜推参与计算） |
| `car_type`, `version` | 3.1.2：1 平推、2 齿条；3/4/5 报未支持。旧手册方案需显式指定，不能把 2027 文件的 4 映射为齿条 |
| `xmin/xmax/ymin/ymax` | 绘图场地范围；暂不作为整车碰撞边界 |
| `control_points`, `optimal_gradient`, `index1..12` | 仅保留参考，不直接套用到独立曲线/目标函数 |
| `key` 等授权字段 | 不导入、不保存、不处理 |
