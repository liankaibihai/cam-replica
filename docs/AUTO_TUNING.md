# 全自动权重与训练参数调优

此模式为本项目独立实现，入口 `camdesign.optimize(project, callback, 'auto-tune-v1')`。它不是原版缺失函数的恢复，也不承诺任意车体与赛道都存在可行凸轮。

## 搜索什么

用户确认的范围是六项评分权重和训练参数。默认8组配置，每组上限600轮，之后最多2组固定目标约束精修。首组保留当前路线和权重（有上次保存的实际权重则作为起点），迭代上限取原训练轮数与配置上限的较小值。其他组在原始路线和当前最佳候选之间交替开始。

| 参数 | 搜索范围或策略 |
|---|---|
| 六项正基础权重 | 各自基础值的0.25～4倍；基础0保持禁用 |
| 控制点数 | 输入点数、18、34、50；三次样条增点优先保形 |
| 路线模型 | 固定用户当前已应用模型，不在第4、8等组自动切换；B3/B5目前明确拒绝全自动，应选内点法 |
| 贝塞尔阶数 | 固定用户当前已应用阶数，不自动改变 |
| 插值密度 | 目标约301、601、901、1201，按区间数换算 |
| 探针距离 | 0.05～8 mm，对数取样 |
| 学习率 | 0.15～2，对数取样 |
| 平滑率 | 0～0.25 |
| 调节间隔、指数 | 10～100轮、0～1.5 |
| 初始搜索步长 | 输入值的0.25～4倍，限制0.01～100 mm |
| 每组轮数 | 随机分配上限的50%～100%；第2组使用全部上限 |

默认种子2027，使用局部随机流，不改调用方随机状态。有限配置搜索不等于全空间穷举。三次样条模式没有贝塞尔阶数这一生效参数，精修也不使用梯度搜索学习率/平滑率；显示必须标明阶段。精修使用两次内点法，局部名义差分分别0.01、0.001 mm，采样数不低于统一比较网格。精修依赖 Optimization Toolbox，缺少时明确记录跳过原因，不伪称执行。

2026-10-31修复后全自动锁定模型及阶数，逐回调和返回时核对。数量重配置须经过[几何映射门禁](MODEL_MAPPING.md)，自动阶段最多扩至 `max(50,输入点数)`，防止隐式膨胀到250点造成不可预期算量；无法保留路线的配置记为失败并跳过。`info.routeModelLocked/fixedRouteModel/fixedBezierDegree`记录锁定值，分组`mappingFitInfo`记录转换误差。下面2026-10-30长测属于旧多模型策略的历史证据，不代表当前锁定策略质量。

传动比35（或用户手动输入值）、车体尺寸、目标点顺序、固定首节点、压力角/转角/打卡容差/回程门限、场界不允许被自动修改。代码对这些数据建立不可变签名，每次回调和最终输出都核对。既有“按违规调权”设置被保留，但全自动每组内部冻结权重，不叠加另一个动态调权器。

## 怎样判断较好、怎样拒绝不准

1. **统一比较网格**：由本次输入确定，路线至少601点、最多2001点，凸轮至少721点、最多1441点。各组训练密度可以不同，比较时回到同一网格；不以稀网格的低分胜出。
2. **每组独立加密**：统一网格及4倍网格分别检查全部离散轮廓交叉、打卡、压力角、转角、欠切、回程、节点和五个部件中心的场界。2026-10-31修复后另要求完整几何访问事件序列与目标一致，不能跳过提前经过或重复经过；圆半径使用现有打卡几何容差并注明非RFID实测范围。
3. **物理门限优先**：通过全部检查的候选优先；未通过时按最大归一化违规程度、交叉数、固定基础权重参考分排序。六项权重变化后的动态分不能用于跨组宣称改善。
4. **最终领先三组复核**：还检查8倍统一网格以及候选自身训练网格和2倍训练网格。4倍与8倍的压力角差≤0.25°、打卡误差差≤0.5 mm、转角差≤0.1°、回程角差≤0.05°、路线长度差≤2 mm，才标记数值稳定。上述为数值收敛检查，并非放宽用户物理门限；任何网格物理不达标仍拒绝。

5. **轮廓与反推闭合**：4倍、8倍实际轮廓在同一凸轮相位的最大坐标差须≤0.05 mm；用8倍理论凸轮独立RK4积分回推前轮，最大位置闭合误差须≤2 mm。这两项是数值一致性容差，不是加工精度或实际接触承诺。

只有全部物理门限和数值收敛同时通过，`info.verifiedFeasible` 才为真。未通过时仍返回最佳候选供继续研究，并保留失败项，不把“完成训练”“分数降低”“求解器成功”写成验收通过。稳定但不符合回程要求的解析直线例也必须失败。

## 记录和显示

基础权重始终保存在 `params.weights`；所选实际权重存 `params.autoTune.selectedWeights`，完整项目保存/导入可以恢复。训练设置随最终候选回填。历史含实际权重、固定参考分、实际评分、配置编号、分组轮数、累计轮数、实际训练参数及统一比较网格。

信息栏默认“自动显示实际”。固定参考分用于同尺度观察；实际贡献表用于说明本组在优化什么。不同组之间参考分可能回升，因为正在试验另一组起点，不能称为单一路径连续下降。最终候选以验收排名选择，不一定是最后一组。

`check_auto_tune` 是短合同及解析门禁检查；`check_auto_tune_quality` 才是正式太阳能初赛平推输入、足够预算的质量实验。结果见[本次变更](changes/2026/2026-10-30-005-auto-tuning.md)。

独立原始34节点起点的对照请求600轮，求解器实际100轮后因步长停滞且约束不满足自然停止，未超时。训练网格压力约36.88°，8倍却达86.52°并有5对自交，4/8倍峰值差46.59°；轮廓坐标差仅0.0101 mm、理论回推误差仅0.0241 mm，仍不能代替压力角和交叉门禁。此候选被拒绝；这一次对照不能证明全局无解或原始种子更优。[数值摘要及证据哈希](../data/auto_tune_independent_seed_20261030.json)。
