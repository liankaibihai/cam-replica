| 源码位置 | 直接可读的计算 |
|---|---|
| 12–24 行 | 默认 `name='tulun2'`、`.txt`、`data=2`；d=130、r=5、l1=70、l2=200、l3=620、T=200、ratio=0.2、num=1000。注释表示直径、半径、杆长、周期长度等，未显式统一声明 mm；不能作为队伍实测尺寸 |

| 42–52 行 | 杆端点以前一点为初猜，反复投影到以 p1 为中心、半径 l2 的圆，再将 X 强制为 x_l3，直到杆长误差≤1e−10；没有最大迭代数或不可达检查 |
| 54–56 行 | `p3=p2-[0,l3]`，长杆保持竖直；l1/l2/l3影响杆端和末端竖直轨迹，但未进入后述凸轮半径表达式 |
| 59、63–67 行 | 直接令理论半径 `rho=d/2+x_T-x_v`，相位 `phi=j*2*pi/num`，理论点 `q=rho*[cos(phi),sin(phi)]`；相位按索引均匀分配，不来自车轮累计行程 |
