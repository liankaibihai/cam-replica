# 模型与算法范围

## 正向计算

项目由目标、节点／控制点和参数组成。路线模块计算前轮及相关参考点轨迹，再按机构模型生成凸轮工作段与回程段，计算几何指标和诊断信息。

当前机构包括平推与齿条。基本位移关系分别为 `h = c*tan(delta)` 和 `h = c*delta`。这些是本项目模型中的参数约定，不能直接套用到不同接触形式的机构。

传动比读取输入值。程序不会为获得较好结果而自动增加传动比；其他硬件尺寸和物理验收阈值也不由搜索器任意修改。

## 路线表示

- 三次插值样条：以路线节点构造曲线。
- 独立贝塞尔融合：使用 Bernstein 窗口及本项目定义的融合权重、端点修正和解析导数。
- 标准三／五次 B 样条：保存系数控制点、固定节点向量及端点导数约束；目前使用内点法后端。

独立贝塞尔融合不等于恢复某个第三方软件的融合函数。模型之间的映射以实际曲线为对象，不直接把不同语义的控制点数组换名使用。

## 搜索方法

峰值梯度与加权四方向使用本项目的评分、探针和接受规则。可行性优先四方向先比较约束违规，再在可行范围内比较独立质量指标；六项评分可作参照或辅助提案，不等于最终接受标准。

约束后端使用 `fmincon`。接力搜索先进行四方向搜索，再进行 SQP 精修；多起点接力按明确起点和共享预算执行。全自动调优比较允许范围内的权重和训练设置，锁定已应用的路线模型及阶数。

部分搜索结构受教学资料中的数学思路启发，但评分、边界、学习调度、触发和接受策略具有本项目自己的定义，不宣称复现第三方软件的完整优化器。

## 真正的候选并行

前台协调者冻结本轮基础路线，将独立的正负 X／Y 探针交给候选线程计算。每次在飞数量受所选线程数限制，结果仍按原索引归并；候选排序、接受和完整检查不按完成先后顺序改变。

预算只有一个所有者。提交前预留额度，返回后结算实际尝试，失败也计数。无法确认是否执行的尝试保留为未知预留，不冒充准确次数或自动退款重试。候选 worker 不接收可变预算对象或界面对象。

并行不降低采样数、不跳过完整／加密检查，也不保证所有输入都加速。线程调度和数据准备本身有成本。

## 轮廓与反推

实际轮廓反推使用冻结折线的接触几何与车辆积分；理论凸轮对照是不同路径。闭环报告区分接触合法性、积分收敛和几何门禁。

当前模型不完整描述间隙、弹性、摩擦、轮胎滑移、机构制造误差或现场 RFID 性能。离散检查也不是连续几何性质的严格证明。
