# 路线画法的文献检索与适配比较

检索日期：2026-10-31，Asia/Shanghai。基线 `e949d328b9226c122e544e16cb77cdddb6248cb7`。本轮是文献与源码适配评估，没有接入或运行新规划器，不能把推荐次序当成实测精度排名。

**建议优先增加标准B样条控制点参数化，比较三次与五次；保留现有两种路线作基线。第二方向是曲率变化率连续的G³路径，回旋线可作为初始路径生成器。** 这些方法都需要接入有序传感器打卡、固定传动比、完整凸轮和场界约束，不能直接使用赛车论文的最小曲率目标作为加工验收。

## 与现有两种画法的比较

路线表示决定如何由控制量得到连续曲线；峰值梯度、四方向、内点法决定如何搜索控制量。换求解器不能自动提高曲线接缝的连续阶次。下面是结构与接入判断，不是计时/精度排行榜。

| 画法 | 结构与优点 | 对当前项目的不足 | 选型判断 |
|---|---|---|---|
| 现有三次插值样条 | 穿过路线节点；一般拼接处C²；已有保形增点和完整车辆链 | 移动一个插值节点经样条求解影响其他段；C²不等于所有高阶变化平顺，更不保证压力角合格 | 保留作可靠的已有基线，不能称它过时或必然不准 |
| 现有独立贝塞尔融合 | 重叠Bernstein窗口归一化；控制点通常不在曲线上；可调阶数和局部形状 | 本版融合与起点修正不是作者原版函数；高局部次数不等于全局高连续阶次，仍有曲率、奇异切线与接缝检查 | 保留对照；目前不建议继续只靠升到15阶解决波动 |
| 标准三次B样条 | 控制点为基函数系数，局部支撑；在简单内节点通常C² | 在相同节点/边界对应的函数空间中可表示同一三次样条，单纯改写表示不增加平滑等级 | 适合作为“局部参数化是否改善求解”的消融组 |
| 标准五次B样条 | 简单内节点C⁴；导数解析、局部可控，可研究对尖峰和高阶变化的影响 | 更多自由度或支撑范围不自动降低峰值；必须约束端点、打卡和正向运动，避免病态参数化 | **优先试验候选**，这是适配判断，尚无胜出证据 |
| G²回旋线样条 | 曲率在每段随弧长线性变化，连续曲率连接；已有MATLAB接口 | 拼接的曲率斜率可跳变；通过指定点不代表传感器正确读卡；车辆中心定义必须一致 | 适合生成几何合理初值；不能无条件作最终凸轮路线 |
| G³曲率参数化 | 直接描述曲率变化率连续，更便于给转向变化设限 | 需解带状态积分的非线性约束问题；多打卡点、相位及终点处理复杂，接入成本较高 | 第二研究方向；若B样条仍难解，可考虑独立后端 |

数学补充：五次B样条的C⁴性质以简单内节点为条件；重复节点会降低连续性。B样条与分段贝塞尔可以表达同类多项式曲线，区别常在控制变量、节点分布、接缝约束与目标函数，不是名称决定精度。低阶分段贝塞尔加明确连续性约束也值得试验，不能从现有独立融合失败推断整个贝塞尔家族不好。

## 为什么不能只追求弯道更圆

当前计算链见 `+camdesign/route.m`、`camProfile.m`：前轮路线先由后轮无侧滑约束积分出车身航向，再得前轮转角和主动轮行程。论文常用的后轴曲率关系 `tan(delta)=L*kappa_rear` 不能直接套到前轮路线曲率。打卡对象是偏置的传感器，前轮曲线穿过目标不等于传感器穿过目标。

当前平推模型内部有：

```text
q = d/2 + c*tan(delta)
phi = 2*s_drive/(D*i)
alpha = atan(abs(dq/dphi)/q)
```

这是现有模型公式，不是本轮论文推导恢复的原版公式。小曲率或小转角不保证小压力角；需要关注转角随主动轮行程/凸轮相位的变化。`camProfile`还会将离散工作段中心距重新拟合为三次样条，并接五次回程；上游换成C⁴路线也不会使整个数值链自动成为C⁴。接缝、局部极值及回程须一起验收。

**一个可直接算出的长度预算**：当前测试主动轮直径130 mm、传动比35、回程要求60°，工作段主动轮行程必须满足

```text
s_drive <= pi*130*35*(1-60/360) = 11911.872145 mm
```

此前候选主动轮行程12299.432369 mm，超出这一预算约387.56 mm，因此回程只有50.2393°。这些尺寸除35外仍是测试配置，不宣称实车测量。把弯道加大、减少曲率，可能进一步增加长度；这说明最小曲率只能作为目标之一，不能替代凸轮相位约束。

场界也不能只检查控制点：B样条凸包性质最多可帮助约束所表示的参考曲线，不能自动约束偏置轮心、传感器或完整车体外廓。传感器有序访问仍需独立建模；返回地球的位置重复不意味着前后航向及曲率必须强行周期相同。

## 现有数值证据能说明什么

[完整自动调优记录](../data/auto_tune_quality_20261030.json)共3890轮，候选5为三次插值样条、50节点；最终8倍复核压力角49.0302°、回程50.2393°、从动轮中心出界38.4975 mm，未达标。

该运行的贝塞尔组4/8分别是34控制点、10/5次、345/309轮，三次组的起点、节点数、权重、探针和轮数均不同。因此只能说“本次配置搜索选中了三次候选，仍不合格”，**不能说三次算法已被证明优于贝塞尔**。新B样条、回旋线、G³还没有本赛道结果，本轮不伪造胜率或压力角改善百分比。

## 可执行的公平比较方案

最小接入边界是新增独立路线表示与求值器（位置、一阶/二阶导数及明确的参数区间），让 `route` 继续执行同一个前轮到车身的积分与传感器变换。节点编辑、验证、存档、训练密度和优化变量映射也要识别新表示；不能只在下拉框加名字，或把B样条系数送回现有穿点插值函数。曲率/转角参数化则需要独立状态积分入口，首版不与换B样条同时改车辆模型。

1. 固定太阳能初赛有序点、平推、传动比35、相同尺寸、初始位姿、传感器偏置及全部验收阈值。打卡暂定30 mm与实际RFID识别范围分开。
2. 第一阶段只换路线表示：现有三次、现有独立贝塞尔、标准三次B样条、标准五次B样条。使用同一物理评价链及求解后端，关闭自动换模型、动态调权等混杂项。
3. 将同一几何初值拟合到各表示，报告拟合位置/切向/转角差；不能把同一个XY数组直接当作插值节点和B样条系数。用相近有效自由度分档比较，记录控制点、节点重数和端点约束数。
4. 固定一组基础权重做第一轮消融；每组至少5个成对初值/种子。预先给相同模型评价预算（建议每次50000次、每组总250000次起），同时报告实际迭代、求解与总墙钟时间。若仍改善，再按相同规则扩展所有有关组；局部停滞不当作证明无解。
5. 同一4/8倍网格复核压力角、打卡、回程、自交、欠切、轮心场界与反推闭合；另在内节点/融合接缝两侧和尖峰邻域自适应加密，避免均匀采样漏峰。增加规则检查与实际车体外廓所需数据，不将五中心检查冒充全车合规。
6. 排名先看严格可行率，再看最坏违规及达标余量、对初值的稳定性，最后比较耗时和路径长度。论文耗时、现有不同配置结果、变尺度评分都不用于直接排名。
7. 若B样条方案通过模型验收，再开展原版同输入图片/点位对照与实车验证。原版此前13点、比值20的截图不能作为当前太阳能固定35的精度基准。

结论：已有文献与代码足以支持增加一个标准、便于求导的路线表示；目前最值得试的是三次/五次B样条对照，并把压力角和主动轮行程放进约束。是否实际优于现有两种，必须由上述同条件实验决定。
