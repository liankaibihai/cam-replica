## 比赛的整体目标

太阳能车是能源转换、机械转向、制造装配、读卡播报和现场应变的综合项目。太阳能板通过充电模块向超级电容储能，再驱动电机及电子模块；机械传动让凸轮相位与轮子行程关联，凸轮通过平推机构控制前轮。它不是比赛中依靠电子传感器闭环追线的车辆。

初赛自带已充电的一个超级电容模组，现场不安排充电；决赛使用统一模组，通过规定充电环节储能，现场决赛太阳能板与系统断开。决赛规定模组最大充电电压7.94V、输出7.4V±0.1V、最大2A；这些不能直接当作电机端电压电流。全车仅一台电机，转向只能用机械机构；不能额外安装传感器或借无线通信实施动作。读卡和电能检测是命题明确规定的模块。

最大宽200mm、长250mm，包括软质线路；太阳能板小于车外形。外壳、读卡器内置、语音可听范围、检测模块安装等都是独立要求。某些文件对外壳不合格的处罚表述不同（命题取消资格、评分第9页给出扣分），保留冲突，赛前向当届裁判/补充通知核对，设计上满足完整外壳要求。

## 场地与路线

场地6000×2000mm，喷绘布可能伸缩，坐标以现场为准。初赛访问顺序：地球→金星→太阳→谷神星→天王星→冥王星→鸟神星→木星→水星→地球，共10次访问。16个条目是备选序列，其中首末地球同位置；决赛点及情景点现场公布。

每轮调试3分钟、运行3分钟，指令后须在15秒内启动，运行中停止15秒亦结束；两轮取最好成绩。调试和正式上场阶段不可随意换零件，创新实践阶段的按题制造替换是另一个环节。不能把软件随时换凸轮的能力理解成比赛调试时允许换凸轮。

## 成绩与软件分数的区别

| 层级 | 构成 |
|---|---|
| 初赛总成绩 | 文档20%＋作品创意10%＋现场70% |
| 现场初赛 | 标记30＋有效距离40＋语音30 |
| 决赛总成绩 | 创新实践20%＋充电10%＋现场70%，另有A/B/C等级先后 |
| 现场决赛 | 标记40＋电能消耗20＋有效距离40；情景点权重现场给出 |

有效运行距离不是实际曲线弧长：正常按序覆盖点之间计直线距离，漏点、停止、超出下一点、反向有单独算法。初赛太阳能最长有效距离不超过12238mm。软件总路程可用于凸轮相位/运行估计，不能直接放进官方距离评分。

充电评价单位太阳能板面积的充电平均功率；决赛耗电项评价运行消耗能量除以时间的平均功率，并与各队极值归一化。没有实测耗能、时间和赛事归一化数据，不能计算可信的完整官方成绩。缩短路线、降低转角变化/压力角可能帮助运动，但不是已经证明降低耗电。

## 几何经过、读卡和判罚必须分开

评分第3页要求车身铅垂投影全覆盖UID标签，四周不可见；正确顺序经过时LED一次点亮、离开后熄灭。语音另有正确内容、一次播报及停止要求。红圈直径40mm，UID直径17—30mm且现场确定；它们都不是已经标定的RFID感应半径。

评分第9页明确整车投影压场界结束；重复经过或乱序、错误次数达到三次、漏必经点也有终止规则。起终点地球属于规定重复访问。需区分车体覆盖事件、RFID触发事件、指示灯事件、语音事件、计分事件，不能仅用传感器点距圆心判决全部行为。

供应商V2.4手册有晚启动/缓启动、失去UID约0.5秒后灭灯、蓝牙调参、2S电池兼容等说明：这只是硬件能力。比赛供能仍按超级电容条款，比赛中无线动作受禁；实际固件延时需与车速和覆盖时间共同验证，不能把厂家默认值认定合规或稳定读卡保证。

## 现有程序逐项对应

| 项目 | 已核对现状 | 后续重点 |
|---|---|---|
| 太阳能初赛点序 | 点库及solarTestProject使用正确10次访问 | 现场坐标测量与配置版本 |
| 路线→凸轮→反推 | 已有数值和接触闭环证据 | 与比赛裁判规则分别报告，不推翻已有数值验证 |
| 越界 | trajectoryBounds保留五种中心轨迹；CHG-013新增独立整车外包络双网格诊断、严格碰线拒绝和地图定位 | 补本队实测外廓；尚非连续扫掠，也未进入优化约束 |
| 访问顺序 | visitOrderAudit保留圆区事件；CHG-013新增独立连续遮挡内接矩形全覆盖UID事件，区分起终点再次进入、乱序及多余访问 | 补实测覆盖区与标签；实际读卡、LED及语音仍须验证 |
| 六项评分/动态权重 | 优化代理目标 | 保留；单独建比赛记录/评分，勿冒充官方分 |
| 总路程 | 工程弧长 | 另算官方有效距离 |
| 电能与时间 | 本轮未发现已验证实测能耗模型 | 接入实际采集日志后才能评价功率 |
| 现场改题 | 已有模型切换/重建与导出 | 以制造时间、调试流程、冻结可加工方案为目标 |

优先次序：准确的车体覆盖与场界模型→实测读卡窗口及启动/相位重复性→官方距离及事件记录→能耗与制造流程。数学上算准与实车跑准都需要，但前者不能独自保证后者。
