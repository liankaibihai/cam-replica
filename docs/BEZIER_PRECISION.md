# 贝塞尔路线到凸轮的数值精度

本次改进保留独立融合贝塞尔的控制点、融合权重、参数长度和端点修正，改变的是曲线之后的数值计算链。选中“贝塞尔曲线（控制点调形）”后重新计算即使用新方法；无需改传动比或提高贝塞尔阶数。它仍是本项目独立实现，不是原版3.1.2源码恢复。

## 发现的问题

固定两条保存的太阳能平推路线、传动比35，用另一套de Casteljau曲线求值及ode113自适应积分作参考。原有位置、一阶、二阶导数及首末几何语义正确；主要误差在后续步骤：

- 航向用RK4，而主动轮与前轮行程用梯形积分，行程误差影响凸轮相位。
- 旧凸轮工作段用离散相位/半径重新拟合三次样条，再从样条端点取一阶、二阶导数接五次回程。接缝可以是C²，但所匹配的导数仍可能偏离原路线。
- 历史理论反推用PCHIP重新插值半径，与生成轮廓采用的工作段函数不是同一函数。

在其中一条35控制点、五次Bezier保存路线中，旧回程轮廓相对独立数值参考的最大差为：601路线点7.98381 mm、4801点0.453794 mm、9601点0.127588 mm。单独提高行程积分精度几乎不能消除这项误差，解析回程端点导数才消除了主要偏差。这是固定输入的数值诊断，不是迭代优化结果。

## 当前计算方法

1. **解析求导到三阶**：融合Bezier仍表示原曲线；增加其三阶导数，直接推导转角对路线参数的一阶、二阶变化。
2. **同步积分**：主动轮行程与航向采用同一组RK4阶段；前轮弧长使用对应的中点与端点速度积分。避免以较低阶的相位计算拖累后面的轮廓。
3. **解析凸轮导数**：由物理传动比将路线参数导数转换为凸轮相位导数。平推用`h=c*tan(delta)`，齿条用`h=c*delta`，硬件输入保持不变。
4. **五次Hermite工作段**：每段同时匹配端点半径、一阶和二阶导数；回程也用解析端点条件。保存`cam.workPP`，供理论反推和多项式压力极值审计使用。

若路线参数为u，相位为φ，计算关系为：

```text
dq/dφ = (dq/du) / (dφ/du)
d²q/dφ² = [(d²q/du²)(dφ/du) - (dq/du)(d²φ/du²)] / (dφ/du)³
```

这一步没有通过相邻离散半径差分估算端点导数。相位间隔过小、非有限系数等情况明确拒绝，不静默换回较粗模型。

`route.numericalMethod`和`cam.numericalMethod`记录所用数值链。旧三次插值与标准B样条的计算方法保持；没有`workPP`的历史理论凸轮仍使用原兼容反推。**实际轮廓反推只读取实际XY接触，不读取workPP**，所以仍可用于独立核查。

## 如何理解“更准”

固定paired35路线、同相位比较整圈轮廓对独立数值参考的最大偏差：

| 路线采样点 | 旧计算/mm | 新计算/mm |
|---|---:|---:|
| 601 | 7.98381 | 0.00106663 |
| 4801 | 0.453794 | 0.00000557 |
| 9601 | 0.127588 | 0.000000185 |

旧误差由回程主导；新列为完整工作段及回程的最大误差，不仅挑误差最小的回程。独立自适应积分另外缩紧容差复核，这些微小值仍只表示模型内数值比较。

实际XY是折线，还须单独检查点数。固定quality34路线9601点、反推积分2401/4801点，实际凸轮5761→11521→20001点时，最大传感器路线偏差为 **0.074504→0.018666→0.006178 mm**。每次两档积分期间同一折线不变。固定5761点的新闭环误差没有优于008旧值，不能声称所有误差都同比下降；这项点数收敛说明有限折线也有独立误差。该路线的压力角和回程仍未达标。

固定路线下，增加采样后的轮廓变化更小、相对独立参考更接近，说明数值计算更可靠。控制点经过优化后是否满足压力角、回程、打卡、欠切、自交和场界，是另一个问题。算法不因精度改善而放宽这些条件。

独立参考仍是高精度数值积分，存在参考误差和浮点底噪；有限采样、同模型闭合不能证明真实加工和车辆运动精度。原版同输入数值输出和实车标定仍未完成。具体运行、结果和限制见[本次变更](changes/2026/2026-10-31-009-bezier-precision.md)。

旧新版两组同输入长测及加密续算共4627轮、329060次模型尝试，八个返回候选仍均未满足全部物理条件，且均有自交，实际接触明确拒绝。因此本轮交付结论是**固定贝塞尔曲线的计算精度改善已验证，优化器尚未调出工程合格方案**，不能凭其中压力角变小就推荐加工，也不能据本轮局部预算证明无可行解。
