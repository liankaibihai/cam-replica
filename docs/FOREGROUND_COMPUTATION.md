# 前台执行与默认候选线程

CHG-021按用户要求删除了产品的后台执行模式。计算凸轮、迭代优化、实际轮廓闭环都在前台同步调用；按钮回调在结果完整发布或停止处理完毕后才返回。没有“后台计算/前台兼容/强制后台取消”菜单，没有可脱离前台的业务任务服务。

候选多线程保留，默认开启、4线程，可在“候选线程”菜单明确选择2线程或关闭用于诊断。可行性四方向和接力中的四方向阶段直接支持；其它后端按原求解器同步运行，日志明确目前未接入候选并行，不修改用户开关、不因默认开启就拒绝这些后端。

主线程使用内部候选线程池提交有限窗口，等待本批完成并按原索引归并。无需协调进程、进程池或NumThreads配置，不删除已有池。资源不足4线程时明确拒绝，用户可选择2线程或关闭；不静默声称已并行。池资源预检发生在清空历史/优化信息之前。

每批完成后drawnow处理停止等事件；StopCheck在批次结算后允许结束搜索。单个数值调用仍可能短暂占用前台。账本只在主线程归并，失败计数、Reserved未知额度、完整/加密验收规则保留。每批futures由专属handle容器及其绑定onCleanup方法管理；异常退栈只取消并等待自身future，不影响无关任务。

旧窗口只在空闲时显式调用 `migrate_foreground_execution(camReplicaApp)`。迁移先备份完整项目、结果、历史和待应用输入，再删除旧执行菜单和旧任务appdata，默认候选4线程。忙碌、编辑/反推或残留活动旧任务拒绝迁移。重复迁移保留已明确选择的诊断开关。关闭的用户窗口不会被重开。

使用说明以本页为准，019/020的异步模式和协调进程说明是历史记录，已被本次取代。历史输出、备份和源码快照未删除。
