## 实施顺序与验收问题

1. **本轮 F03/F04：地图编辑与部件显示。** 11 项回调/状态检查及既有界面回归已通过，预览和确认后截图已审视。真实鼠标验收窗口已启动，但 Computer Use 报用户停止；用户要求恢复后重试仍返回停止状态，尚未完成原生点击和键盘焦点验收。
2. **太阳能项目工作流。** 用正式点库创建平推候选，把发车位置与正式访问序列分开；继续标出未测量的车体参数，不把回归样例当实车方案。
3. **原版对照与路线生成。** 在可恢复试验副本固定输入，先比较可见坐标和轨迹，再隔离路线融合与几何公式差异。缺少权重函数时保留独立样条参考实现。
4. **训练、回溯与动画。** 逐项实现可证实的交互语义；算法候选须单独命名、独立验证，不用“AI”名称替代具体计算说明。

这些是项目内的开发次序，不是定时任务，也不表示未实现的功能已经通过验收。每次改动进入 [独立变更记录](changes/README.md)。
