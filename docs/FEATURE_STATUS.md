## 实施顺序与验收问题

补充证据：长教程已恢复[可见原始特征前端](BEZIER_SOURCE_AUDIT.md)，7组检查通过，但未知聚合与完整评分仍未补齐。[四档采样诊断](changes/2026/2026-10-29-006-resolution-study.md)显示默认及300轮候选的工作压力角超限随加密保持，不能靠增采样解决。

约束后端的充分预算、差分和密求解网格诊断也已完成收尾：部分候选粗网格违规为0，加密后仍超压力角/打卡阈值或出现欠切/自交。功能检查的通过不能填作工程合格；CHG-010不包含后续原版UI对照。

1. **优先核心算法与原版对照。** 用户本轮已指出优化波动与已给算法未落实。已完成失败基线、峰值改进与候选加权实验，仍未达工程阈值；继续围绕路线融合、评分和调度差异取证与实现，不能以界面完成代替。固定同输入比较可见坐标和曲线；缺少权重函数时保留独立样条参考实现。
2. **地图与界面剩余验收。** 主图、方向与参考圆的布局/回调检查已通过；11项地图回归及既有界面回归通过。此前原生鼠标验收受Computer Use停止状态影响，真实命中与焦点仍未完成。
3. **太阳能项目工作流。** 已有正式点库平推测试入口；优先解决长预算候选的压力角与轮心出界，补实际发车配置、完整车体外廓与识别范围。现有节点边界不能当作整车边界，不把测试尺寸当实车标定。
4. **训练、回溯与动画。** 补齐可证实的等待、局部最优存档与动画交互语义；算法候选须单独命名、独立验证。

这些是项目内的开发次序，不是定时任务，也不表示未实现的功能已经通过验收。每次改动进入 [独立变更记录](changes/README.md)。
