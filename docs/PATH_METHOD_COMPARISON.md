# 四种路线表示的太阳能赛道比较

状态：2026-10-31 已完成20组主实验与4组密网格追加。四种表示均未得到全面合格的候选；新增标准三次／五次B样条保留为可切换实验选项，默认仍为三次插值。B3数值稳定性较好，B5没有显示优势，不能从这些局部试验推断整个方法家族优劣。新增实现不是原版算法恢复。文献依据见[研究报告](PATH_METHODS_RESEARCH.md)及[专用文献会话复核](PATH_LITERATURE_REVIEW.md)。

## 为什么选它

标准 B 样条直接以系数控制点调形，固定基函数可以解析求导，有局部支撑。五次、简单内节点时路线是 C⁴，三次是 C²。与三次 B 样条一起比较，才能区分“控制点表示”与“次数提高”。车辆航向积分、偏置传感器和凸轮工作段三次重拟合／五次回程仍用同一条计算链，因此上游 C⁴ 不是最终凸轮精度保证。

本轮没有移植赛车库或新增工具箱依赖；基函数使用 Cox–de Boor 递推，求导解析实现。直接配点／多重射击与直接凸轮运动规律参数化仍是后续独立方向，不混入这次表示消融。

## 尖峰与验收范围

除了4/8倍网格，本实验对8倍路线重建的完整凸轮分段多项式，逐段求 `q''q-(q')²=0` 的实根和区间端点，计算压力角 `atan(|q'/q|)`。工作段与回程均检查，含所有段接缝；另用 `q'=0` 检查中心距最小值。结果称“8倍重建凸轮多项式极值审计”，不声称证明精确连续车辆轨迹、实际接触或制造误差。曲线参考路径的所有接缝自适应积分与整车外廓碰撞尚未实现。

排名先看严格可行率和数值稳定性，再看违规项与余量、跨初值一致性和耗时。求解结束、分数降低、返回正退出码都不替代工程验收。达到预算但仍改善的组须按统一规则继续诊断；局部停滞不说明物理无解。

## 实际结果

主实验实际 **10,134轮、714,235次模型尝试**；单组实际75–600轮，部分由求解器判局部不可行提前结束，不能伪称每组都跑满600轮。未触发时间上限。数值稳定为4/8倍指标差、同相位包络差和理论反推闭合共同检查，不等于满足物理门限。

首套Bezier与B3到预算末仍改善，同时发现采样漏峰，因此对**同一套初值的全部四种方法**分别追加最多600轮、50000次函数预算，训练网格加倍至1201/1441；物理参数和最终共同网格不变。追加实际 **2,292轮、159,033次模型尝试**，B3在492轮以局部不可行停止，其余600轮。追加单独存档，不混入主实验5初值统计。

追加后旧插值、B3、B5仍返回原有候选；Bezier得到不同候选但仍失败。部分其他主实验初值到600轮仍有改善，未逐一无限延长；这些结果只说明该预算、初始化与求解设置下的表现，不能证明全局无可行解或继续计算绝无收益。

**当前选择**：保留旧三次插值为默认；标准B3可作为后续研究候选，因为本次5/5数值稳定，但它的物理指标未全面优于旧算法。B5不作为优先默认：5/5均未过数值稳定检查，回程表现也没有优势。后续重点是有序打卡与完整凸轮约束的联合求解、工作／回程连接的稳定处理；不能凭提高曲线次数宣称更准。

首套额外4/8/16倍诊断显示：Bezier和B5的8→16倍包络差仍分别约0.3262、0.3845 mm，主要最大差位置在回程附近。不能只因压力峰值变化很小就宣布整个轮廓收敛。此处是数值现象定位，尚未证明其唯一原因。

主实验后段seed5、seed4-B5及追加实验使用独立实例并行计算，墙钟时间有CPU负载混杂，**不据此做纯速度优劣排名**。模型尝试计数包含后端验收，外部加密审计另计。数值核心在全部正式运行中冻结；报告恢复／无效值处理与UI修复未改变求解方程和候选。

## 与原版和实车的关系

本轮比较的是本项目四种路线表示，共用当前独立车辆／凸轮模型。原版此前的另一条赛道、另一传动比截图不能作为本轮准确度基准。尚无原版同输入导出，也没有实际凸轮加工／跑车结果；通过本轮也只能说明模型内可行与数值一致。
