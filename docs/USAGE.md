# 使用说明

## 开始计算

1. 在仓库根目录运行 `app = launch_cam_app();`。
2. 检查车体参数、路线画法、目标表和节点／控制点表。长度单位为 mm，界面角度为度。
3. 点击“计算凸轮”，查看路线、转角、轮廓与诊断结果。
4. 修改训练参数后，先点击“保形应用”或“还原”，再计算或优化。待应用输入不会由计算按钮自动丢弃。

本项目以左转为正。车体局部原点为前轮转向轴，X 向右、Y 向前。不要将不同软件的坐标、符号或机构参数直接混用。

## 调整路线

三次样条通常通过路线节点；贝塞尔和 B 样条的控制点不等于必经点。修改模型、阶数或控制点数量时应观察整条曲线变化。

“保形应用”检查位置和切向误差，必要时可能增加控制点。界面分别显示请求数量与实际数量；保留原数量不代表减点成功。

“强制调整（允许改形）”是显式手动操作：先保存完整状态，再按合法请求数量拟合。它允许超出保形误差门限，但仍检查参数、有限几何和首末约束，并显示实际误差。可用“恢复备份”恢复操作前的状态。改形成功不表示新凸轮满足物理门禁。

地图编辑可用于选择和移动节点；确认后应用，取消或 Esc 恢复编辑前状态。

## 优化与候选线程

计算和优化是前台同步操作，回调在处理完成后返回。支持的候选搜索默认开启 4 个线程，可在“候选线程”菜单选择 2 个线程或关闭并行用于诊断。

| 方法 | 候选线程范围 |
|---|---|
| 可行性优先四方向 | 同轮冻结路线的坐标探针并行 |
| 接力／多起点接力 | 仅四方向阶段的探针并行；SQP、阶段和起点仍按原顺序执行 |
| 其他方法 | 原同步后端；不因并行开关默认开启而拒绝运行 |

线程资源不足时会明确提示，不会偷偷换成串行并声称已并行。内点法、SQP 与接力需要 Optimization Toolbox。

点击“停止”后，会在数值调用或候选批次的适当边界处理请求，完成已启动尝试的结算。单次数值调用期间可能仍需等待。退出清理只处理本次提交的候选 future，不关闭共享池或取消无关任务。

动态权重并不适用于所有后端。若优化按钮不可用，先阅读界面的常驻原因提示；切换方法或关闭动态权重须由使用者明确操作。

## 保存、导入与导出

使用“保存项目”保存当前项目为 MAT 文件。导入只读取支持的项目／参数格式；不同版本的机构编号不能自行假定相同。请仅导入可信来源的 MAT 文件。

导出提供候选几何和参数报告，不能代替制造审查。保存项目、手动调整前的状态备份和导出报告用途不同，应分别保留。

## 判断结果

检查压力角、转角、欠切、自交、访问顺序和场界，而不是只看总分下降。不同权重下的动态评分不能直接当作同一尺度比较。

采样模型检查通过、加密后数值稳定、原软件一致、实际车辆可用是不同结论。部件中心轨迹不越界也不代表整车外廓或 RFID 识别通过。使用前应根据自己的机构和实验数据独立验证。
