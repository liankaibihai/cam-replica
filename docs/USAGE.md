# 使用方式

在 MATLAB R2025b 命令窗口执行：

```matlab
cd('F:\许昊阳\竞赛\2027工创\.codex\cam-replica')
launch_cam_app
```

无需安装旧版 Runtime，不修改原 EXE。窗口使用 MATLAB 自带的 `uifigure`，正常桌面启动即可；某些受限执行环境可能阻塞图形组件初始化。

队伍实际参加太阳能赛项、机构为平推型；历史生物质能案例保留作算法测试。运行 `check_2027_solar_course` 可核对并导出今年太阳能初赛点位；执行 `c=camdesign.course2027Solar();` 后，`c.preliminarySoftwareMM` 对应原表正 X 坐标。初赛 10 行含起终点两次地球（9 处不同位置），不要去重。当前界面启动时仍加载历史回归样例；点库并不代表已经完成太阳能实车方案。

## 第一次使用

1. 默认沿用 2027 点位和尺寸另建齿条方案。也可“导入 MAT”，选择原文件或本项目 MAT。原 `2027生物质能初赛_直播.mat` 的 3.1.2 类型 4 是顶球，界面会提示该机构尚未实现，可取消或明确选择另建齿条/平推方案。
2. 核对机构、轮径、传动比、轮子与传感器位置。所有车体坐标是前轮轴为原点、X 右/Y 前，不能直接填写世界坐标。
3. 在“打卡点”编辑顺序点位，可选中一行后插入或删除。本版把表中全部点列入几何误差表。只有历史 13 点样例的第 1 行是发车辅助点；太阳能第 1 行为正式起点地球，最后一行为终点地球，不应把辅助点规则套用于其他点集。正式方案的发车位置需与计分点分别设置，当前界面尚无独立发车位置输入。
4. 点击“重建路线”，随后可在“路线节点”调整前轮轨迹的插值节点。这里不是原版贝塞尔控制点。
5. “计算凸轮”显示路线、转角与轮廓。参数修改后旧图仍保留，状态栏提示重新计算，导出会强制重算。
6. “迭代优化”调用独立有限差分梯度法；“停止”在当前梯度轮结束后生效。第一点固定，其余节点允许移动。
7. “固定凸轮反推”进入试调模式：固定当前理论凸轮，修改左侧车体参数，再点“更新反推”查看路线变化。“退出反推”恢复原设计参数。
8. “导出候选”会在所选父目录内建立新子目录，保存项目、CSV、无表头 XYZ 点集和报告，不覆盖原软件资料。

## 参数与评价

原版截图中的两行机械参数，对应本版本左侧参数表的前六行。“小车类型”对应上方机构选择框，目前支持齿条和平推。3.1.2 编号为 1 平推、2 齿条、3 周转、4 顶球、5 斜推，不应与旧手册混用。

用户已确认：队伍实车为平推型，原版界面中的参数均为作者默认值。下表及默认项目用于说明和测试，不是实车配置；轮径、传动比、车体坐标、机构尺寸需要从队伍 CAD 或实测确定后再设计凸轮。

| 原版参数及本例数值 | 几何含义及本版用途 |
|---|---|
| 主动轮直径 D=130 mm | 将主动轮行程转换为车轮转角；应使用实际滚动直径 |
| 总传动比 i=20 | 主动轮转数/凸轮转数；凸轮转一圈，主动轮转 20 圈。不是动力源到主动轮的减速比 |
| 转向偏距 c=25 mm | 齿条时为转向齿轮分度圆半径；平推时为推动点运动直线到前轮竖轴的距离。符号表示安装侧 |
| 推杆半径 r=2 mm | 与凸轮接触的曲面半径，可以对应圆柱轴或轴承外圆；在本模型中用于圆形接触包络补偿 |
| 基圆直径 d=100 mm | 原版特殊命名：直行基准态下推面中轴到凸轮中轴距离的两倍；本例零位中心距为 50 mm |
| 凸轮厚度 f=5 mm | 原版帮助明确仅用于斜推型计算；本版仅支持平推/齿条，厚度随项目和报告保留，不改变二维轮廓，也未生成厚度实体 |

以主动轮累计行程 s 为输入，本版使用 `φ=2s/(D*i)`，φ 为凸轮相位（rad）。D=130、i=20 时，一圈凸轮对应主动轮行程 `π*130*20≈8168.14 mm`，不等于前轮或传感器路线长度。齿条 `h=c*δ`，平推 `h=c*tan(δ)`；δ 为转向角（rad）。零位中心距 d/2 加机构位移形成理论接触中心轨迹，再按接触圆的包络计算实际轮廓。r 的补偿沿轮廓法线，不能一般性地逐点从极径减 r。

界面现将旧“滚子半径”改称“推杆接触半径 r”，避免误认为只能安装滚动轴承。内部字段 `rollerRadius` 保持兼容，仍采用理想圆形接触模型，不模拟摩擦差异。

- **零位中心距 ×2**：对应原 d；不是通常机械设计定义中的实际基圆直径。
- **转向偏距 c**：齿条按 h=cδ，平推按 h=c tanδ；c 可为负，俯视且车头朝上时，原版正值表示凸轮在前轮右侧、负值表示在左侧。具体旋向和装配零位仍需核对。
- **传动比**：本版明确采用主动轮转数/凸轮转数。自动调整开启时，实际结果可能增大，见日志和 `report.json`。
- **初始前轮转角**：默认 0；发车方向是车身方向，二者不要混淆。
- **回程保留角**：工作结束后补全至一圈；回程参与压力角和包络检查，不作为比赛继续行驶路线。
- **压力角/转角/打卡容差**：本版本用户设定的工程评价阈值，不是官方规则数值。

## 固定凸轮试调

适用问题：凸轮已经定好，改变轮径、齿轮半径、安装中心距、轴距或传感器位置，路线会怎样变化。

进入反推时固定设计凸轮、前轮起点和原路线；界面传动比初始化为设计中实际使用的传动比。左侧只显示参与反推的参数，自动传动比、机构切换、节点编辑、优化和候选凸轮导出暂时禁用。改变轴距时请同时修改主/从动轮 Y，保持共轴。

黑色虚线是试调后的传感器轨迹；状态栏分别给出同一凸轮相位下相对原设计的最大偏差，以及试调路线的最大打卡偏差。两者含义不同。退出时恢复全部原设计参数，试调数值不会自动覆盖设计方案。

示例：在默认齿条设计中将轮径从 130 改为 132.6 mm，固定凸轮不变，界面检查测得同相位最大传感器偏差约 155.16 mm。这是本项目理想模型的预测，并非实车误差，也不是原版对照结果。

本功能从理论凸轮半径反算转角，因此不模拟滚子实际接触、背隙、弹性或打滑；滚子半径和厚度不会改变这个理想反推模型，试调表中不显示这些无效变量。

独立目标为各归一化项的加权和：

| 项 | 定义 |
|---|---|
| 打卡 | 平均 `(有序投影距离 / 几何容差)^2` |
| 长度 | 前轮路线长度 / 目标点折线长度 |
| 平顺 | 平均 `(100 × dδ/ds_front)^2` |
| 压力角 | 平均 `(超限压力角 / 10°)^2`，包含工作与回程 |
| 转角 | 平均 `(超限前轮转角 / 10°)^2` |
| 欠切 | 平均 `max(0, 0.1-(1-rκ_pitch))^2` |

轮廓交叉在最终完整检查中报告；不使用隐蔽剪点来消除交叉。该优化器不保证全局最优，也不保证有限轮数内满足所有阈值。加权平均可能容忍局部峰值，必须一起看最大压力角和最大打卡偏差。

## 输出含义

- `project.mat`：本项目独立 schema，不能承诺原软件可直接读取。
- `cam_actual_candidate.csv`：补偿滚子半径后的二维轮廓候选。
- `cam_pitch.csv`：理论轮廓、接触中心半径与压力角。
- `cam_actual_xyz_mm.txt`：三列 X/Y/Z，mm，无表头，Z=0。尚未实际验证导入某一 CAD 软件。
- `route.csv`：前轮、传感器轨迹与转角。
- `checkpoints.csv`：按顺序投影到传感器路线的几何误差。
- `report.json`：完整参数、实际传动比、检查结果与警告。

这里的“未检出自交”仅针对离散采样折线。加工前还需要考虑轮廓分辨率、装配旋向、孔/轴、厚度、加工公差、接触动力学及实车误差。

## 命令行与扩展

```matlab
project = camdesign.defaultProject();
project = camdesign.importProject('你的原始文件.mat');
result = camdesign.evaluate(project);
[better, history] = camdesign.optimize(project);
result = camdesign.evaluate(better);
camdesign.exportResult(better, result, fullfile(pwd,'outputs','my_candidate'));
```

后续可把 `route / camProfile / evaluate` 用作强化学习环境的计算接口。先校准和验证模型，再替换优化器，避免把仿真偏差误认为算法提升。

3.1.2 原文件的类型 2 才是齿条。若只借用顶球文件的参数另建齿条方案，必须显式选择：

```matlab
[project, notes] = camdesign.importProject('2027生物质能初赛_直播.mat', ...
    MechanismOverride='rack');
```

命令行固定凸轮试调：

```matlab
project = camdesign.defaultProject();
result = camdesign.evaluate(project);
actual = project.params;
actual.wheelDiameter = 132.6;
simulation = camdesign.simulate(result.cam, actual, ...
    result.route.front(1,:), deg2rad(actual.headingDeg), ...
    GearRatio=result.cam.effectiveRatio);
```

`simulate` 未指定 `GearRatio` 时使用设计结果的实际传动比；要研究更换传动齿轮的影响，显式传入新的物理传动比。固定的是同一组凸轮相位与理论半径，不能先用试调参数重新生成凸轮。

未知版本不会自动猜测编号；只有确认文件采用旧手册编号后，才使用 `TypeScheme='legacy-manual'`。上述转换保留原机构记录，不沿用原版控制曲线，不表示两种机构凸轮相同。

运行 `run_tests` 做核心检查，`check_app` 做界面与操作检查，`run_demo` 做 15 轮示例。PowerShell 脚本 `run_matlab_checks.ps1` 提供批处理入口，临时偏好目录与日志只写到被 Git 忽略的 `local/`。
