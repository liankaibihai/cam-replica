# 动态评分权重

本功能为独立实现，不是原版动态评分函数恢复。用户要求动态控制评分规则；第一版按违规程度调整惩罚权重，默认关闭，支持峰值梯度与原加权四方向搜索。内点法、历史算法及新增[可行性优先四方向](FEASIBILITY_SEARCH.md)明确拒绝启用状态，不能在单次求解中偷偷改变目标函数。可行性优先模式仍允许编辑基础六项权重用于辅助提案，其接受规则使用独立可行性／质量排序。

[接力精修与多起点](RELAY_MULTISTART.md)也明确拒绝动态调权，沿用相同固定质量目标进行阶段间和起点间比较；不会暗中关闭开关，也不会自动更换路线模型或物理门限。

## 设置与公式

入口在左侧“权重”页：勾选“按违规自动调权重”，再修改四项调节参数。表格区分基础值和实际值，上方显示记录来源。底部下拉选择“固定参照评分”或“本轮动态评分”，相应六项贡献表跟随切换；固定参照趋势始终保留，动态趋势单独标明权重会变。

基础权重仍为用户设置的六个值，保存于`params.weights`。可选`params.dynamicWeights`包含enabled（开关）、interval（调节间隔，默认10轮）、gain（违规增益，默认2）、maxMultiplier（基础权重最大倍率，默认5）、response（响应比例，默认0.5）。缺字段按默认读取，不修改旧项目。

第1轮及其后每隔interval轮，使用当前候选计算违规量v：

| 分项 | v的定义 |
|---|---|
| 打卡偏差 | max(0,最大打卡误差/打卡容差−1) |
| 路线长度 | 0；保留基础权重 |
| 转向变化 | 0；保留基础权重 |
| 压力角超限 | max(0,整圈最大压力角/压力角上限−1) |
| 转角超限 | max(0,最大转角绝对值/转角上限−1) |
| 欠切风险 | max(0,(0.1−最小欠切余量)/0.1) |

目标权重`wTarget=wBase×min(maxMultiplier,1+gain×v)`；更新`wNew=(1−response)×wOld+response×wTarget`，并限制在基础权重至最大倍率之间。违规改善后权重可以逐渐回落。长度和转向变化没有对应工程违规阈值，因此固定为基础权重。基础为0表示用户关闭该评分项，程序不会自行恢复为正值。欠切风险的0.1沿用原评分软惩罚尺度，真正几何验收仍要求余量大于0。

每次搜索开始先确定本轮权重，再用同一组权重重新评分当前候选、所有探针、回溯与平滑候选。不能让新候选对比旧权重下的缓存分数。调权追加历史记录，迭代号可能重复；`weightUpdateIteration`记录权重供哪一轮使用，`weightChanged`保留调权标志，不因运行阶段event随后变为searching而丢失。

## 两种分数

固定参考分始终为基础权重乘六项指标之和，记录在history.score。动态搜索分使用activeWeights，记录在history.dynamicScore。前者可以比较同一训练的改善趋势；后者跨调权事件尺度发生变化，不能仅用高低声称进步。每条历史保留referenceWeights、activeWeights、weightMode及weightUpdateIteration；缺失旧历史不得从当前输入推测。

权重只影响优化优先级，不修改传动比、轮径、压力角上限、打卡容差、回程角和几何验收。评分仍只有已有六项，不能据分数低认定自交、出界和回程等额外门禁已经通过。

## 验证边界

短合同检查验证分数与权重一致、静态兼容、取消、保存导入和后端限制；长预算用同一34节点太阳能平推输入、固定35、静态与动态各300轮比较，因末尾仍改善延长为各600轮。

| 600轮结果（8倍复核） | 静态 | 动态 |
|---|---:|---:|
| 固定参考分（优化网格） | 38.08645 | 39.34466 |
| 最大压力角 / ° | 69.15441 | 68.84898 |
| 最大打卡偏差 / mm | 9.11456 | 14.02005 |
| 实际回程 / ° | 51.64684 | 51.76292 |
| 自交段对数 | 0 | 0 |
| 加密工程门禁 | 未通过 | 未通过 |

动态末轮压力角权重由基础3调整到8.78585，其余五项仍为基础值。压力角略低，但打卡偏差和固定参考分更差，不能称整体改善。600轮仍以轮数上限结束，末100轮参考分仅约0.0017的变化；本轮已经延长诊断，不把该平台期当作全局最优或无解证明。单个初值不能证明动态权重普遍更好。完整结果见[变更记录](changes/2026/2026-10-30-003-dynamic-weights.md)和[数值摘要](../data/dynamic_weights_20261030.json)。
# 评分表显示更新（2026-10-30）

默认选择“自动显示实际”：匹配当前计算的权重记录到达后，六项表自动显示实际权重及贡献；没有匹配记录则显示固定参照并标注待记录。用户手动选固定或动态时保持该选择，动态缺失会显示待记录空表。固定参照趋势始终使用基础权重。[变更记录](changes/2026/2026-10-30-004-auto-score-view.md)。
