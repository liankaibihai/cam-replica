# 四方向搜索与短路线目标

用户目标是较短行程、较小打卡偏差和合理凸轮压力角。贝塞尔是路线表示，四方向是控制点搜索动作；新可行性优先策略为本版独立实现，不是原版完整评分/调度恢复。实现和测试状态见[CHG-014](changes/2026/2026-10-31-014-feasibility-first-search.md)。

## 为什么分阶段

旧四方向`video-four-direction-v1`使用本版六项峰值加权分，长度下降可能抵消某项超限增大；固定比回程和中心轨迹场界未进入该训练分数。新策略先比较约束违规，达到完整离散模型可行后，只在保持门限满足的候选中比较长度、偏差和压力角。旧后端保留，便于同初值对照。

新入口`feasibility-four-direction-v1`：未可行时按归一化违规平方和、最大违规、质量目标依次排序。快速探针省略自交计算，实际接受前必须完整检查，最佳代理候选失败后继续考察其他坐标候选。硬门限判断使用精确条件，比较数值容差不用于放松验收。采用原四方向整套候选改善加权思路，并增加独立门禁、回溯及探针收缩/扩大；并不声称与原版优化过程数值一致。初稿单一违规方向在600轮实验中效果不佳，后续`violation-and-reference-four-v2`增加六项固定分引导的辅助方向；两种提案共用探针结果，最终都由相同可行性/质量规则决定是否接受，辅助分降低不自动获得接受资格。

当前质量排序版本为`feasibility-four-ranking-v2-small-error-margin`。令`a`为压力偏好采样的整圈最大值、`aLimit`为用户压力限值、`margin=min(0.5°,0.1×aLimit)`，质量目标为：

`前轮长度/目标折线长度 + 0.2×[(RMS偏差/容差)^2+(最大偏差/容差)^2] + 0.03×(a/aLimit)^2 + 0.02×max(0,(a-(aLimit-margin))/margin)^2`。

压力偏好在当前工作段函数上使用4倍凸轮相位网格，并加入工作段采样位置；它没有重新加密车辆积分，不能替代最终4/8倍完整计算，也不是连续极值或实际接触压力证明。常用35°门限对应34.5°的柔性偏好，正式门限仍是35°。上述系数是本版选择，不是原版参数，不保证全局最优。进入训练可行后，后续接受的候选须继续保持完整训练网格可行；此前允许接受违规下降的未可行候选。六项峰值总分保留作参考并引导辅助提案，不直接决定候选接受。新模式不使用六项动态调权，启用该组合时明确拒绝。

历史初稿与第二版提案实验仍保存旧排序：长度系数1、偏差0.02、压力0.01，没有额外余量项。第二版虽能缩短路线，但24 mm量级偏差和8倍压力超限说明该偏好不符合当前“小偏差＋压力余量”的目标；不能用旧排序数与新版直接比较降幅。

硬门限沿用用户项目：打卡偏差、整圈最大压力角、转角、欠切、回程、中心轨迹场界、启用的控制点边界，以及离散自交/访问顺序。不能通过增大传动比、放松门限或换模型消除违规。未提供车身外廓和UID覆盖区时，只能说机构/中心轨迹模型的检查状态，不能称比赛合格。

## 长度口径

前轮路线长度用来比较路线长短；主动轮行程直接决定凸轮工作角。无滑动模型下，工作角为`360×主动轮行程/(π×轮径×传动比)`。轮径135 mm、比35且要求至少60°回程时，主动轮工作行程须不超过约12370.02 mm。该预算来自当前机构和回程设置，不是官方有效距离或原版显示长度。

用户提供12238 mm是原版计算后用于凸轮利用率的参考，输入和轨迹口径尚未逐项核验，不硬编码成路线目标。

## 判断效果

对照固定共同初值、控制点数、阶数、车体、阈值和采样。报告请求/实际迭代、调用量及停止原因，检查足够预算后的趋势。分别列前轮/主动轮长度、最大/均方根打卡偏差、工作/回程最大压力角、剩余回程、越界、自交和访问顺序；随后在4/8倍网格复核。不同排序值或动态尺度的下降不能替代物理指标改善。

完整几何可行、加密验收通过和实际轮廓接触闭环分别报告。未通过不能仅凭某个指标更低就称最终设计更好；本版数值对照不代表原版逐点一致或实车跑准。

## 本队同初值结果（2026-10-31）

独立贝塞尔34控制点、5阶、训练601/721点、固定比35。两种方法均600轮后再续600轮；新方法累计187245次搜索评价，旧法165087次，轮数相同不等于运算量完全相同。下表统一采用8倍网格，旧法指**本版旧加权四方向**，不是原版3.1.2。

新候选短42.410 mm，压力余量较好，仍保留约0.91 mm的打卡偏差；旧候选打卡更准但压力略超限。这是一个更符合本次门限目标的折中，不是所有指标同时占优。两者都因迭代预算结束，末段仍有小幅改善，不声称已经取得最优解。

最终新候选另以冻结5761点实际轮廓、1201/2401积分进行接触驱动反推：最大传感器闭合差0.042651 mm，积分加密差0.000047223 mm，实际接触压力34.287748°，反推最大打卡偏差0.899113 mm。数值闭环及本模型几何门禁通过；未包含加工、间隙、滑移或RFID/整车投影认证。
