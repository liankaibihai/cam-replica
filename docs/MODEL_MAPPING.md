# 路线模型映射与全自动模型锁定

用户要求切换模型时保留路线，全自动不得自行改变画法。当前通过“应用训练设置”执行真实几何映射，**不再把经过点直接改名成控制点**。

## 使用与结果说明

1. 选择路线画法、阶数和请求控制点数量，点击应用。程序以当前真实前轮曲线为来源。
2. 优先使用可表示同一分段多项式的精确转换；否则受约束拟合。必要时自动增加控制点，最多250。
3. 日志报告精确保形／容差内映射、独立网格最大与RMS位置误差、全程切向差、请求和实际点数。实际数量回填训练栏。
4. 超出门限就拒绝，当前项目、节点、结果和原图保持；待应用设置不冒充已生效。用户可以还原设置或选择另一模型。

“重建路线”是从目标重新生成路线，显式手动移动／删除节点也是改形操作，不能与模型映射混同。

## 判定门限

| 检查 | 默认门限 |
|---|---:|
| 全程最大位置差（同一参数） | 0.05 mm |
| 全程位置RMS差 | 0.01 mm |
| 全程切向夹角差 | 0.05° |
| 首末位置差 | 1e-7 mm |
| 首末参数导数差 | 1e-7 |
| 首末切向夹角差 | 1e-5° |

拟合网格与验收网格不同；验收使用12001点半格偏移采样、源／目标分段边界及邻侧。合同另在32003点网格复核。首节点按位保持，不能用容差放松全自动的起点锁。端点位置与全参数导数由线性约束固定。

精确路径指源曲线空间包含于目标空间（如cubic插点、cubic→B3、适当重数的B样条升阶），并经过数值复核。数值拟合只标“容差内”，不是数学上处处恒等，也不是连续曲线误差的严格上界证明。拟合网格很密仍不能代替最终凸轮、压力角与数值收敛验收。

## 已确认的比赛路线结果

在太阳能平推、固定35、34节点cubic上：转换B3使用36控制点，B5使用102控制点，最大位置差约4.6e-12 mm。B5保留原cubic的C²连续性，没有把路线偷偷平滑成另一条C⁴曲线。这与旧四方法比较中36系数、均匀简单节点的B5不是同一参数化或自由度，不能直接套用旧优劣排名。

同一路线转独立Bezier5，到250控制点时最大位置误差约0.01144 mm，但全程切向差约0.11637°，因此**拒绝**。历史34控制点Bezier5转3阶也不能满足当前门限，拒绝并保留原方案。平滑小夹具的Bezier阶数转换可在门限内完成。这说明不能承诺任意两种有限维模型都可严格互换，不以放宽误差或隐藏原模型来实现“看起来没变”。

## 全自动

全自动固定当前已应用模型和独立Bezier阶数，只调整六项权重与适用训练参数。数量转换仍接受上述门禁，但自动增点上限为 `max(50,输入点数)`；失败配置跳过且记录原因，不用错误坐标继续训练。B3/B5现阶段仅支持内点法，选择全自动会明确拒绝而不替换模型。

接口：`camdesign.mapRouteModel(project,mode,count,degree)`；`applyTrainingSettings`返回顶层`info.fitInfo`，`setControlPointCount`返回`info.fitInfo/actualCount`。研究入口`toBSpline`保留原均匀拟合协议，必须查看误差，不等于产品映射门禁。

## 验证入口

- `check_model_mapping`：精确空间转换、Bezier拟合、真实比赛路线接受／拒绝、独立网格和原输入保持。
- `check_auto_model_lock`：四组配置覆盖旧第4组切模位置，逐回调检查模型／阶数及硬件锁，B样条不支持组合明确拒绝。
- `check_model_mapping_ui`、`check_bspline_ui`：真实应用回调、误差文本、实际点数、保存导入、固定凸轮和地图操作。
- `check_auto_model_lock('quality-cubic')`／`('quality-bezier')`：新目录充分预算实际运行；不同初始表示，不用作等几何方法排名。已存在长测结果时拒绝覆盖。

模型映射通过不表示路线符合所有比赛规则、凸轮可加工或实车必然打卡；所有物理门限及最终加密门禁保持。
