# 路线模型映射与全自动模型锁定

用户要求切换模型时保留路线，全自动不得自行改变画法。当前通过“保形应用”（原“应用训练设置”）执行真实几何映射，**不再把经过点直接改名成控制点**。

## 使用与结果说明

1. 选择路线画法、阶数和请求控制点数量，点击应用。程序以当前真实前轮曲线为来源。
2. 优先使用可表示同一分段多项式的精确转换；否则受约束拟合。必要时自动增加控制点，最多250。
3. 日志报告精确保形／容差内映射、独立网格最大与RMS位置误差、全程切向差、请求和实际点数。实际数量回填训练栏；训练说明与状态栏显示请求→实际。若同模型减点最终保留原数量，明确显示“未减点”，不是减少自由度成功。
4. 普通应用超出门限就拒绝，当前项目、节点、结果和原图保持；待应用设置不冒充已生效。用户可以还原输入、选择另一模型，或明确使用强制切换。

### 强制切换与重建

训练页提供独立的“强制调整（允许改形）”入口（原“强制切换”），供需要按指定点数调整或无法满足保形门限但仍需换模型的情况使用。它按请求的合法点数拟合，不再自动增加到旧点数或250；低于目标次数所需最少点数则拒绝，不暗中钳位。程序仍从真实曲线拟合，保留首末位置与参数导数；显式允许超出全程位置、RMS或切向误差门限，不会把旧节点直接解释为另一种控制点。普通应用及全自动的严格规则不变。

强制操作记录实际最大位置差、RMS和全程切向差；`withinTolerance=false`不被改写为通过。它允许改形，并非提高了转换精度。非法参数、非有限几何或端点约束失败仍拒绝。

强制前备份完整原项目、原计算结果和待应用的界面输入，并提供恢复入口。新模型发布后旧凸轮、评分和优化记录作废；如果新路线暂时无法计算凸轮，保留新模型和路线供节点表调整、保存或重建，明确显示未计算原因，不再把旧凸轮当作新结果。

训练页底部两行固定按钮分别为“保形应用／还原”和“强制调整（允许改形）／恢复备份”。“还原”只撤销待应用训练输入；“恢复备份”还原最近一次主动改形前的项目、历史、待应用输入、诊断及视图缩放，保留切换和恢复的操作日志。完整MAT位于仓库`local/model_switch_backups`，路径同时显示在训练页和日志中，不进入Git。备份文件包含`backup`会话结构，不作为普通项目MAT导入；跨窗口可用`camReplicaApp.restoreModelSwitch('完整备份路径.mat')`恢复。存活窗口源码兼容及回调恢复见[使用说明](USAGE.md)，不能以清空工作区代替输入保全。

“重建路线”直接读取当前所选模型和合法训练输入，从目标重新生成新路线，不要求先通过旧路线的保形映射。因此切换被拒后仍能重建。它与手动移动／删除节点一样属于改形操作，不保证原路线不变。完整操作与证据见[本次变更](changes/2026/2026-10-31-010-force-model-switch.md)。

## 判定门限

| 检查 | 默认门限 |
|---|---:|
| 全程最大位置差（同一参数） | 0.05 mm |
| 全程位置RMS差 | 0.01 mm |
| 全程切向夹角差 | 0.05° |
| 首末位置差 | 1e-7 mm |
| 首末参数导数差 | 1e-7 |
| 首末切向夹角差 | 1e-5° |

拟合网格与验收网格不同；验收使用12001点半格偏移采样、源／目标分段边界及邻侧。合同另在32003点网格复核。首节点按位保持，不能用容差放松全自动的起点锁。端点位置与全参数导数由线性约束固定。

精确路径指源曲线空间包含于目标空间（如cubic插点、cubic→B3、适当重数的B样条升阶），并经过数值复核。数值拟合只标“容差内”，不是数学上处处恒等，也不是连续曲线误差的严格上界证明。拟合网格很密仍不能代替最终凸轮、压力角与数值收敛验收。

## 已确认的比赛路线结果

在太阳能平推、固定35、34节点cubic上：转换B3使用36控制点，B5使用102控制点，最大位置差约4.6e-12 mm。B5保留原cubic的C²连续性，没有把路线偷偷平滑成另一条C⁴曲线。这与旧四方法比较中36系数、均匀简单节点的B5不是同一参数化或自由度，不能直接套用旧优劣排名。

同一路线转独立Bezier5，到250控制点时最大位置误差约0.01144 mm，但全程切向差约0.11637°，因此**拒绝**。历史34控制点Bezier5转3阶也不能满足当前门限，拒绝并保留原方案。平滑小夹具的Bezier阶数转换可在门限内完成。这说明不能承诺任意两种有限维模型都可严格互换，不以放宽误差或隐藏原模型来实现“看起来没变”。

## 全自动

全自动固定当前已应用模型和独立Bezier阶数，只调整六项权重与适用训练参数。数量转换仍接受上述门禁，但自动增点上限为 `max(50,输入点数)`；失败配置跳过且记录原因，不用错误坐标继续训练。B3/B5现阶段仅支持内点法，选择全自动会明确拒绝而不替换模型。

接口：`camdesign.mapRouteModel(project,mode,count,degree)`默认严格且`AllowControlPointIncrease=true`。手动强制入口同时传`AllowApproximate=true, AllowControlPointIncrease=false`，固定合法请求数；只传`AllowApproximate=true`的旧低层调用仍保持原来允许增点的兼容行为。`applyTrainingSettings`禁止全自动请求这两种手动例外，并返回顶层`info.fitInfo`；`setControlPointCount`返回`info.fitInfo/actualCount`。研究入口`toBSpline`保留原均匀拟合协议，必须查看误差，不等于产品映射门禁。点数修复证据见[CHG-018](changes/2026/2026-10-31-018-training-controls-feedback.md)。

## 验证入口

- `check_model_mapping`：精确空间转换、Bezier拟合、真实比赛路线接受／拒绝、独立网格和原输入保持。
- `check_auto_model_lock`：四组配置覆盖旧第4组切模位置，逐回调检查模型／阶数及硬件锁，B样条不支持组合明确拒绝。
- `check_model_mapping_ui`、`check_bspline_ui`：真实应用回调、误差文本、实际点数、保存导入、固定凸轮和地图操作。
- `check_force_model_switch`、`check_force_model_switch_ui`：严格拒绝→手动强制→完整恢复、待应用失败模型独立重建、非法输入／残缺备份拒绝、凸轮计算失败时新路线保留及旧结果清理。
- `check_auto_model_lock('quality-cubic')`／`('quality-bezier')`：新目录充分预算实际运行；不同初始表示，不用作等几何方法排名。已存在长测结果时拒绝覆盖。

模型映射通过不表示路线符合所有比赛规则、凸轮可加工或实车必然打卡；所有物理门限及最终加密门禁保持。
