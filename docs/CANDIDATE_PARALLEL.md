# 候选线程并行

当前默认启用4个候选线程，主线程同步求解并等待内部候选完成；可明确选择2线程或关闭用于诊断。可行性四方向和接力四方向阶段支持；其它方法保持同步原后端并说明当前不适用候选并行。

同轮探针冻结best、原索引归并、单预算所有者、失败/未知预留及原完整/加密门禁不变。无需协调进程池；直接使用主线程所属的候选线程池，资源不足明确提示。详见[前台执行说明](FOREGROUND_COMPUTATION.md)。
