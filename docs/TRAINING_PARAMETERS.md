# 训练参数与独立贝塞尔路线

用户于2026-10-30明确选择可切换的独立贝塞尔实现。这里说明本版计算语义；原版完整融合权重和调节函数尚缺，名称相近不表示原版数值等价。对应[CHG-016](changes/2026/2026-10-29-016-training-controls.md)。实现与验证状态以该记录为准。

## 使用入口

运行`launch_cam_app`，点击左侧常驻“打开训练设置（九项）”，或切到“训练”页。默认保留三次插值样条；路线画法选择“贝塞尔曲线（控制点调形）”后可设置阶数（独立实现），点击“应用训练设置”才重算。修改未应用时，计算、保存和优化会要求先应用或还原，避免图形与输入不一致。初始设置与只读的本轮实际参数分开显示。独立模式50控制点、15阶、插值11会生成540个路线采样；这是一组功能检查配置，长预算实验仍未通过加密门禁，不能当成推荐设计参数。

控制点可通过数量输入、节点表增删和地图移动操作改变，实际数量与采样数会同步显示。“应用训练设置”现名为“保形应用”：从真实曲线映射，必要时自动增点，超限拒绝；请求→实际在训练说明和状态栏显示，保持原数量会注明“未减点”。要按指定点数调整，重新填入请求数后点“强制调整（允许改形）”：按合法请求数拟合，不自动增回旧数量，可接受保形误差超限并报告误差，操作前自动备份。规则见[模型映射](MODEL_MAPPING.md)。显式手动拖点或删除某一经过点也会改变路线。“重建路线”从目标按当前选择的模型和合法训练输入生成新路线，不再因旧路线映射失败或待应用标志而被挡住。

强制切换／重建成功发布新模型后，若凸轮暂时无法计算，旧凸轮和旧评分作废，新路线仍保留供节点表调整、保存或再次重建；不把计算失败伪装成合格结果。普通“应用训练设置”继续保持严格的成功发布／失败保留行为；原“还原”只撤销待应用训练输入，完整路线恢复使用备份恢复入口。

## 参数如何参与计算

先分清两层：“路线画法”决定怎样用点生成曲线（三次插值、独立贝塞尔、标准三次／五次B样条）；“优化方法”决定怎样移动这些点（峰值梯度、四方向加权、内点法）。两者不是同类算法；标准B样条首版只配内点法。“梯度”“四方向”描述搜索动作，不表示用了训练好的神经网络。

本版峰值/四方向搜索已经具有动态调节：连续试探没有改善时把探针距离减半；已应用训练设置时按间隔/指数衰减学习幅度与平滑候选系数，接受的移动步幅还会自适应变化。它们记录在history的probeMM、learningScale、scheduleScale、scheduledStepMM、smoothingAlpha中，不能将界面初始值覆盖成当前值。内点法使用自己的线搜索，不能把本版学习率衰减说成内点法行为。用户新增原版截图显示3.125、0.0625、0.01875等训练值，只能结合前后操作确认变化，尚不足以恢复原版精确调度。

原版动态变化本身已有实操证据：[对照记录](REFERENCE_COMPARISON.md)记下训练中梯度力16→8，结束后设置框回到64；平滑率及插值数也变化。因此输入设置与运行实际值需要分开，停止后的设置框不能冒充末轮运行值。新增history.plannedSmoothingRates记录本轮计划尝试的平滑系数序列，实际尝试次数见smoothingAttempts，smoothingAlpha记录接受的系数；旧历史缺字段时显示未记录。

传动比与这些训练量不同：太阳能默认35，用户可修改，任何优化器均不得自动修改。

新增可选“**四方向（可行性优先）**”：保留±X/±Y试探和学习／平滑调度，先恢复工程门限，再兼顾路线长度、偏差与压力角。每次真正接受前完整检查自交、访问顺序及场界；最终另做4/8倍加密。六项基础分只引导辅助提案，不直接决定接受，动态调权与此模式冲突时明确阻止启动。初始设置、训练网格结果与最终8倍指标分别显示，细节及长预算对照见[四方向搜索](FEASIBILITY_SEARCH.md)。这是本版独立策略，不是原版评分函数恢复；默认方法仍保留峰值梯度。

“接力精修”和“多起点接力”是固定画法上的组合搜索。每个阶段的轮数上限读取“训练次数”，各阶段共享20万次实际模型评价总上限；多起点默认5个启动，不能理解为5份20万预算。四方向阶段继续使用已应用的学习/平滑设置，SQP阶段使用自己的线搜索及0.0005 mm名义差分步长，不把前一阶段的学习率当SQP参数。参见[接力参数和对照](RELAY_MULTISTART.md)。

| 面板项目 | 本版语义 | 适用范围 |
|---|---|---|
| 训练次数 | `params.iterations`请求上限；实际轮数、停止原因另记 | 各优化器 |
| 控制点数量 | 保形应用中是请求数量，必要时保留原数量／自动增加，明确显示请求→实际；手动强制调整按合法请求数量拟合并允许改形，不自动增点。目标列表独立保存 | 路线设置 |
| 插值数量m | 应用设置时换算全局采样数`Ns=(N-1)m+1`，要求101≤Ns≤20001；不是每个不等长参数段恰好m个点 | 路线设置 |
| 贝塞尔阶数d | 连续d+1个控制点构成一个局部Bernstein窗口，要求3≤d≤49且N>d；cubic和标准B样条不使用此值，B样条次数在画法中选择 | 独立贝塞尔模式 |
| 梯度力 | `gradientProbeMM`，峰值/视频启发搜索中为节点±X/±Y试移/差分距离；内点法默认读取此字段作为名义差分步长，按1000 mm变量归一化后的TypicalX规则缩放。单位mm，没有物理力单位 | 各后端含义如左 |
| 学习率ρ | 在自适应搜索步幅上乘`ρ×decay`，坐标探针救援也按该比例试移并重新评价 | 本版峰值/视频启发搜索 |
| 平滑率β | 邻点候选`B'=(1-α)B+α(A+C)/2`；依次试`α=β×decay×[1,.5,.25]`，重新评价后接受。β=0关闭 | 本版峰值/视频启发搜索 |
| 调节间隔K、指数η | 第k轮`decay=(1+floor((k-1)/K))^(-η)`；η=0关闭阶梯衰减，作用于学习幅度和上述平滑率 | 本版峰值/视频启发搜索 |

内点法拥有自身步长、障碍和线搜索机制，不使用这里的学习率、平滑率和阶梯调度；对应四项必须在面板中禁用或拒绝更改。其有限差分默认值确实读取`gradientProbeMM`，所以该项仍可设置；默认名义距离按`max(0.001,min(1,gradientProbeMM))`钳位到0.001～1 mm，再按TypicalX缩放实际探针。例如填6时默认名义距离仍为1 mm。`optimizeFmincon`显式`DifferenceStepMM`选项不经过这一默认钳位，实际值记在info中。更多差分方向等选项使用原有后端接口，不把本版“梯度力”冒称为内点法学习率。

插值数量只在应用设置或明确调整点数时派生`params.samples`。路线计算始终使用当前`params.samples`，最终4倍/8倍复核才能实际增加采样，不能被旧密度字段重置。应用前后的实际点数与采样数应在界面和报告可查。

## 贝塞尔模式的确切含义

`independentBezierBasis`在全局控制点索引参数0至N−1上构造重叠窗口。窗口j使用连续d+1个控制点，内部权重为`t^4(1-t)^4`，首末窗口采用单侧权重，再按权重和归一化。单窗口退化为已有单条Bernstein形式；多窗口权重是本版选择，不是恢复的`Bezier_superposition`。

基础融合提供解析位置、一阶和二阶导数；车辆集成层`bezierRoute`将参数换算到保存的`parameterLength`，并在首段支撑内加入`h(u)×Δv`端点修正。其中`h=span×t×(1-t)^4`，`Δv`是指定初始前轮切向与原始初始导数之差。修正使当前车身航向和初始前轮角实际生效，并在支撑结束处平滑归零。它可能改变控制多边形的原始包络，仍须做完整几何/场界验收。

此模式控制点通常不在实际曲线上；cubic节点是必须经过的插值节点。两者不能直接复用坐标。切换通过真实曲线拟合且检查位置与全程切向；普通应用失败保持原方案，手动强制允许超限并明确标注改形。数值拟合不冒称数学精确保形。所有模式仍使用相同车辆运动学、平推/齿条位移及凸轮模型，原物理阈值不因换模型而放宽。

2026-10-31数值精度升级：上述曲线位置/D1/D2及参数语义不变，增加解析D3，同步RK4计算主动轮行程，直接推导凸轮相位D1/D2，以五次Hermite构造工作段并用解析端点连接回程。目的在于减少相位及回程导数估计误差，不增加控制点或改变阶数；详见[贝塞尔数值精度](BEZIER_PRECISION.md)。提高计算精度不保证一次优化即满足工程门限。

## 标准B样条

`routeModel='bspline-v1'`，`params.bspline.degree`为3或5，保存固定clamped节点向量、参数长度和末端参数导数。`bsplineBasis`提供位置基函数及D1–D3解析导数，`bsplineRoute`直接线性组合系数，没有融合权重或额外起点修正。界面保形转换优先保留原分段位置，并按升阶需要增加内节点重数；把C²的cubic精确升为五次表示后仍是原C²曲线，不自动变为C⁴。

低层研究入口`[q,fitInfo]=camdesign.toBSpline(project,36,5)`仍保留均匀简单内节点拟合协议，固定首点、初始全导数和来源末端全导数；终点位置拟合，36系数点有66有效坐标自由度。它是历史四方法比较使用的显式拟合入口，**不带产品映射拒绝门禁**。界面和`applyTrainingSettings`现在使用`mapRouteModel`，额外固定末端位置、独立网格验收，必要增点并报告实际数。两入口及其控制点数量／连续性不得混同。

仅支持内点法。B样条次数由画法选择，原“贝塞尔阶数”不适用；学习率、平滑率和间隔／指数也不属于内点法。首两点和末两点有关联，手动单独改坏导数会拒绝，不能把它们当独立自由点。固定凸轮试调与设计端点约束分离。新增可比性接口见[约束后端](CONSTRAINED_OPTIMIZATION.md)，正式四组协议与结果见[赛道比较](PATH_METHOD_COMPARISON.md)。

## 交叉点标记（所有路线模型）

标记依据实际凸轮轮廓的非相邻段自交/接触，理论线与实际线正常叠加不计自交。独立段对计数保持原规则；新增坐标一行对应一对段。共线重合的位置不唯一，使用重合区域代表点；容差内近接触也按原检测精度给代表位置。

完整检查未执行时计数为NaN、坐标为空，不画以前结果的红圈。没有交叉的图仅可保留图例示例，不能制造实际红点。修改或重新计算后标记随实际候选更新，不累积旧图元。
