# 成熟约束优化方法的适配

研究与本机检查日期：2026-10-29。对应 [CHG-010](changes/2026/2026-10-29-010-constrained-optimizer.md)。这是独立算法路线，不是声称恢复了原版3.1.2的完整评分及调度。

当前路线细化与场界扩展分别见[CHG-014](changes/2026/2026-10-29-014-route-refinement.md)、[CHG-015](changes/2026/2026-10-29-015-trajectory-boundaries.md)。CHG-015在每个路线站位加入五个参考中心点的四条场界残差，总约束数为`目标数 + 5×路线采样数 + 2×凸轮采样数`，并在最终两档网格验收中同查。节点边界仍独立保留，场界严格按输入范围，无求解器容差放宽；这不是车宽、整车外廓或连续碰撞保证。以下CHG-010的维数、旧默认长预算和节点边界描述保留为当时实现及历史结果，不能当作CHG-015的新结果。

## 选型与难度

**2026-10-31表示扩展**：内点法可优化 `bspline-v1` 的真实系数控制点。`optimizationVariables`用零空间基消去端点线性等式，`info.effectiveDOF/freeVariables`为独立变量数，`endpointConstraintRank`为显式系数约束秩。新增 `EndDerivative=[dx dy]` 可把旧Bezier末导数也固定；cubic需先用`refineRoute(project,[])`冻结相同末导数。默认空值保留旧模型行为。

`RegularizationWeight`默认1e-4保留历史目标；本轮表示比较显式设0，避免系数移动与插值节点移动的正则不等价。`params.controlBoundsPolicy`缺省时旧模型仍约束节点，B样条采用`trajectory-only-v1`；显式设置该策略时仅取消节点／系数多边形门禁，同一五参考中心物理场界始终执行。`controlBounds`保留实际多边形出界诊断和是否执行此门禁，不能仅看`nodeBoundsSatisfied`判定新候选。正式四方法实验统一显式策略，详见[赛道比较](PATH_METHOD_COMPARISON.md)。B样条当前仅内点法，其他后端拒绝。

**2026-10-30规则更新**：用户确定比值35且禁止程序自行改比值。当前核心移除自动增比，增加一个回程角约束，维度为`目标数 + 5×路线采样数 + 2×凸轮采样数 + 1`；计算、原/加密门禁与导出均固定用户输入。下文autoRatio随路线变化的描述仅属于CHG-010～015历史实现，不是当前行为。最新变化见[CHG-2026-10-30-001](changes/2026/2026-10-30-001-fixed-ratio-results.md)。

有成熟方法可以利用。困难集中在把本车的运动学、凸轮接触几何、顺序打卡和可制造性约束正确接到求解器，而不是重新发明通用优化算法。公开赛车路线算法通常没有本项目的凸轮传动与回程，不能直接把其输出当作凸轮加工数据。

## 设计与验收原则

当前模型的计算链是 `节点 → 前轮路线 → 车身航向/转角 → 主动轮行程与凸轮相位 → 推杆位移 → 轮廓`。径向移动滚子模型的压力角按 `atan2(abs(dq/dφ),q)` 计算，其中q为滚子中心距、φ为凸轮转角。因此“小转角”不等于“小压力角”：同样的位移在较小凸轮转角内快速变化，仍会产生较大压力角。只优化路线长度或肉眼顺滑程度不足以约束此量。

内点法与SQP采用同一个归一化路线长度、转角变化率平方均值和很小的节点移动正则项目标；历史 `peak-v2` 分数另行保存用于横向对照。实现中的目标为：

```text
J = weights(2) × 路线长度 / max(1,目标点折线长度)
  + weights(3) × mean((100 × Δ转角/max(Δ前轮行程,1e-9))^2)
  + 1e-4 × mean(((节点 - 初始节点)/1000)^2)
```

这里转角用rad、长度用mm，节点正则取全部节点/坐标的均值，固定首点的移动量为0。`weights([1 4 5 6])` 不参与这个新目标，打卡、压力角、转角和欠切另作为约束。正则项及尺度是独立实现的数值选择，不来自原版源码。整个固定凸轮采样网格均参加约束，避免按变化的工作段掩码拆分而改变约束数组长度。节点场地边界仅约束节点，不构成车辆碰撞或完整曲线场地边界验证。

非线性约束数量为 `目标点数 + 路线采样数 + 2×凸轮采样数`，分别是打卡误差平方比减1、转角平方比减1、压力角平方比减1、`1e-6 - 欠切余量`。最后一项使用小的数值保护余量，用户物理验收仍要求欠切余量严格大于0。凸轮中心距不足等预期无效几何候选返回有限但明显违反约束的值，程序错误继续抛出。

- 固定既定尺寸、机构、打卡顺序和起点，不能偷偷改变直径、偏距或阈值以获得通过结果；自动传动比仍遵循已有项目设置并报告实际值。
- 对有物理上限的量使用约束，路线平滑和长度等用于优化目标；用于历史横向比较的综合评分与求解器目标明确区分。
- 求解期间的约束向量维度固定。最近线段打卡投影、自动传动比分支及工作/回程分段可能产生非光滑性，不能把使用SQP等同于获得收敛保证。
- 无效候选、用户停止、预算耗尽、不可行退出分别记录；不能把所有退出都叫“优化成功”。异常捕获应限于预期的几何无效状态，意外程序错误应暴露。
- 最终结果使用独立加密采样和完整自交检查；报告最大值及阈值，不仅报告平均目标或函数返回码。
- 与旧算法比较使用相同输入、相同阈值，记录实际迭代、调用量、耗时、工作/回程压力角、打卡误差、转角及欠切/自交指标。若预算不同，明确写出，不能作为等计算成本排名。
- 按用户要求，不能用一两轮或提前超时结果判断算法效果。短测只检查接口与效率；质量诊断须给充足迭代/函数调用预算并记录收敛曲线，到预算末仍改善时延长。请求300轮而只实际运行4轮不能写成300轮结果。内点法的8轮短测也不构成充分优化后的结论。

## 实施结果

**实验后端已实施，针对性检查、UI及加密拒绝回归通过；所有记录的默认齿条/平推工程算例均未通过独立加密验收。** 简单可行解析夹具与专用阈值回归不计入工程设计通过案例。数值、原始来源路径和SHA256见[汇总证据](../data/constrained_optimizer_20261029.json)，完整逐轮历史和MAT/PNG留在 `outputs/constrained_optimizer/`。本项不包含正在单独进行的原版UI对照（CHG-011）。

### 实现、预算与记录口径

- `camdesign.optimize(...,'fmincon-interior-point-experimental-v1')` 是新增可选入口；SQP保留为显式API对照。界面默认仍为 `peak-gradient-v2`，没有替换路线、运动学或凸轮几何。
- 冻结全部项目参数、目标顺序及首节点，只优化其余节点的XY。`autoRatio` 设定保留，实际传动比仍按既有规则随路线派生；请求/实际值另存，不能声称实际传动比恒定。
- `history.score`/`metrics.score` 为旧峰值评分，`history.objective` 为保留候选的新目标；`solverObjective/solverMetrics/solverMaxViolation` 记录实际求解迭代，不能把两类记录混作同一曲线。严格零违规候选优先；不为较小目标把它替换成仅在求解器容差内可接受的轻微违规点。
- 未显式给函数预算时使用 `max(2000,4*(自由变量数+1)*(请求轮数+1))`。默认13节点有24个自由变量，300轮请求派生30100次；显式预算原样保留。默认90秒为回调检查的软限，单轮可能越过软限，最终几何复核另计。`elapsedSeconds` 包含后端最终复核，`solverSeconds` 为fmincon阶段；模型尝试次数 `evaluations` 与 `objectiveCalls/constraintCalls` 分开，客户端回调自行重算不计入前者。
- 生产默认仍为前向差分，取项目 `gradientProbeMM` 换算后的相对步长，默认名义0.5 mm；未把某次较好的试验值升为默认。研究选项为 `DifferenceStepMM`、`DifferenceType`，名义步长对应1000 mm变量尺度下、归一化位移绝对值≤1；更大位移由fmincon按TypicalX规则放大。
- 默认求解网格601/721，非线性约束2056项；2倍求解网格1201/1441时4096项。结束后对原网格及4倍区间加密网格分别作完整自交检查，确实完成加密且两档均满足原35°、65°、30 mm、正欠切余量及节点边界时，`verifiedFeasible` 才为真。求解器 `ConstraintTolerance=1e-6` 不加到工程验收阈值上。
