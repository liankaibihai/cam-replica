# 验证说明

## 验证对象

本发行主要面向可检查的数值实现和功能流程。建议使用小型合成输入分别验证：

- 直线、圆弧、机构正反变换与坐标约定。
- 路线／凸轮计算、保存导入和导出的一致性。
- 模型映射、控制点数量、保形拒绝与显式改形。
- 串行与候选并行的结果、物理调用预算及失败计数。
- 前台回调完成后才返回、停止处理、任务专属退出清理。
- 界面显示来源、交点坐标和轮廓使用同一网格与结果。

开发过程中已在 MATLAB R2025b 上进行过此类小型合成检查。发行文件整理后的实际通过情况应以本次运行的测试输出为准，不能把开发记录代替对当前文件的验证。

## 运行检查

请在独立 MATLAB 会话中，将当前文件夹切换到仓库根目录后运行：

```matlab
addpath('tests');
smoke_test;
```

`tests/smoke_test.m` 使用手写直线输入，检查解析转角、行驶距离、命中误差、有限轮廓、发行数据读取、界面计算和默认 4 线程配置。成功时输出 `PUBLIC_SMOKE_PASS`。它不启动完整路线优化，也不证明并行候选的结果、预算和停止行为已经通过全部检查。

扩展检查应使用新的输出目录，避免影响正在编辑的项目或覆盖既有结果。开发阶段的历史测试不作为本发行的运行入口。

没有安装某个可选工具箱时，应区分“不适用／未运行”和“通过”。同样，受控异常退出检查不等于已经测试所有 Ctrl+C、进程崩溃或硬件故障情形。

## 结论边界

本项目不声称：

- 与某一原版软件、特定版本或其完整评分逐点一致。
- 已完成真实车辆、制造精度或比赛合规认证。
- 所有候选都能满足全部几何门禁，或优化总能得到可行解。
- 多线程一定缩短任意输入的总时间。

总分下降、单次小检查通过和数值收敛不能代替完整工程验收。需要针对自己的尺寸、机构、输入网格和目标顺序检查边界，并使用独立测量或解析基准确认结果。

报告问题时，请记录版本、方法、参数、请求／实际迭代数、终止原因和最小复现输入。不要上传密钥、授权文件、私人路径或未经允许公开的资料。
