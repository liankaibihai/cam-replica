## 已恢复的单曲线公式

`Bezier_Curve.m` 原程序使用n+1个控制点P_i，先按杨辉递推求C(n,i)，再计算：

```text
B(t) = Σ C(n,i) t^i (1-t)^(n-i) P_i,  i=0…n
t = 0, 1/num, …, 1
```

点阵可含任意列；当前原脚本绘图仅展示前两列。`num`明确是分段数，输出为num+1点。新增 `camdesign.bezierCurve(controlPoints,segments)` 保留原式乘加顺序和网格，额外检查输入和系数溢出。它不把控制点当插值必过点，也不声称稳定支持无限高阶。

这份手册包含明显与实际脚本不符的main.m、Coordinates/Cylinders、N轴等文字；实现依据以实际 `Bezier_Curve.m` 为准。手册中的BV链接可用于确认资料关系，不能据其他段落补出不存在的函数。

目前生产 `route.m` 仍未替换：单条高阶曲线和多条局部重叠曲线是两层算法。尚缺的仍是重叠窗口、权重、边界和 `Squares_standard_sum/score_cal` 完整表达式。
