# 凸轮路线设计工具

用于研究小车路线、转向机构与凸轮轮廓关系的 MATLAB 工具，提供中文界面、参数编辑、路线计算、优化、轮廓诊断和数据导出。

本项目采用独立实现的数值模型，不是任何商业或第三方软件的官方版本，也不保证与其逐点一致。输出用于研究和设计比较，不构成加工批准、比赛合规结论或实车性能保证。

代码全部由codex完成，蒸馏数篇论文，我相信开源才是真理，介于我当前的进度还未上车实测。本工具包含了大量求解方式多种算法。

## 运行环境

| 组件 | 用途 |
|---|---|
| MATLAB R2025b | 已使用的开发与验证版本；其他版本未保证兼容 |
| Optimization Toolbox | 内点法、SQP、接力搜索，以及全自动调优的默认约束精修路径 |
| 候选线程资源 | 多线程使用 `backgroundPool` / `parfeval`；完整验证环境安装了 Parallel Computing Toolbox，运行时仍会检查可用线程数 |

没有所需优化工具箱时，可使用不依赖 `fmincon` 的计算与搜索方法。候选线程不足时，可明确选择 2 个线程或关闭候选并行，不会自动冒称已并行。

MATLAB 和工具箱需由使用者自行安装并取得相应许可，本仓库不包含其安装程序。

## 启动

下载 [最新发行](https://github.com/liankaibihai/cam-replica/releases/latest) 的源码包并解压，或克隆 `main` 分支：

```sh
git clone --branch main --single-branch https://github.com/liankaibihai/cam-replica.git
```

在 MATLAB 中将当前文件夹切换到仓库根目录，运行：

```matlab
app = launch_cam_app();
```

发行版的小型检查在仓库根目录运行：

```matlab
addpath('tests');
smoke_test;
```

该检查覆盖解析直线路线、数据读取、界面计算和默认 4 线程配置，不等于完整优化或并行正确性验证。

先检查示例的单位、坐标方向、车体尺寸、传动比和目标访问顺序，再替换为自己的输入。示例不代表任何车辆的制造实测值。

计算、优化和闭环检查均在前台同步执行。候选并行默认开启 4 个线程；仅可行性四方向及接力中的四方向阶段支持候选并行，其他方法保持原同步求解。没有可脱离前台的后台业务运行模式。

## 主要功能

- 三次插值样条、独立贝塞尔融合和三／五次 B 样条路线表示。
- 齿条与平推机构模型、凸轮轮廓、压力角和欠切诊断。
- 路线节点编辑、保形映射，以及显式允许改形的指定控制点调整。
- 多种独立搜索方法、候选线程并行、停止与预算计数。
- 实际轮廓接触反推、闭环数值检查、目标访问顺序和采样场界检查。
- MAT 项目保存／导入、候选几何与报告导出。

使用步骤见[使用说明](docs/USAGE.md)，模型与算法范围见[算法说明](docs/ALGORITHMS.md)，测试及结论边界见[验证说明](docs/VALIDATION.md)。

## 文件组织

| 位置 | 内容 |
|---|---|
| `+camdesign/` | 路线、车辆运动、凸轮、评价与优化计算核心 |
| `launch_cam_app.m` / `CamReplicaApp.m` / `cam_*.m` | 启动、中文界面和回调服务 |
| `data/` | 运行所需点位和示例参数 |
| `tests/` | 手写小型发布检查 |
| `docs/` | 使用、算法、验证、经验与变更记录 |
| `RELEASE_MANIFEST.json` | 开发基线及发行文件 SHA256 |

`main` 是面向使用者的发行版本；`feature/reference-comparison` 保留开发历史，不是精简安装包。贡献说明见 [CONTRIBUTING.md](CONTRIBUTING.md)。
