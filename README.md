# 工创赛凸轮设计复现

面向 MATLAB R2025b 的可读源码项目。第一版支持平推、齿条，目标是跑通“打卡点 → 路线 → 转向 → 凸轮 → 反推路线 → 评价/导出”。

这是依据用户提供资料独立实现的功能复现。原 EXE 的应用正文已加密，无法确认它的完整评分公式、曲线生成及候选选择实现。2026-10-28 已实际操作原版 3.1.2、导入 2027 数据并尝试导出；原版要求导出密钥，尚未取得输出点集，因此尚未完成数值等价验证。

**机构编号已纠正：3.1.2 为 1 平推、2 齿条、3 周转、4 顶球、5 斜推。** 2027 文件版本为 3.1.2、类型为 4，属于顶球，不能解释为齿条。默认示例是沿用这些点位和尺寸另建的齿条方案。旧手册的编号不同，导入时必须区分版本。

## 运行

在 MATLAB 中切换到本目录，运行 `launch_cam_app`。核心只使用基础 MATLAB，无需 Optimization、Curve Fitting 或 Parallel Computing Toolbox。

命令行验证：`run_tests`。演示与输出：`run_demo`。默认演示使用 2027 文件中的点位，但其余参数及模型约定须结合实车核对。

## 实现约定

- 长度 mm，角度内部 rad，界面 deg；左转为正。
- 车体局部坐标：前轮转向轴为原点，X 向右、Y 向前；后轮共轴且 Y 为负。
- 平推 `h=c*tan(delta)`；齿条 `h=c*delta`。
- `d/2` 是零转角时的接触滚子中心到凸轮中心距离，不是实际轮廓最小半径。
- 独立三次插值样条描述前轮轨迹；不把原版高阶贝塞尔控制点直接当作本版本的样条节点。
- 本版本的几何接触模型为平面径向移动滚子包络。平推、齿条的实际安装形式必须满足这个假设。
- 优化分数是本项目的几何目标函数，不是工创赛官方成绩。
- 导出是待复核的几何候选：不含孔、厚度实体、加工公差或制造认证。

详细拆解、字段映射、公式和验证边界见 [拆解说明](docs/REVERSE_ENGINEERING.md)，具体操作见 [使用说明](docs/USAGE.md)，测试结果见 [验证记录](docs/VALIDATION.md)，原版实操和对照进度见 [对照记录](docs/REFERENCE_COMPARISON.md)。

## 当前版本 v0.2

已实现中文界面、齿条/平推、点表增删改、按版本识别的 MAT 参数与点位导入、路线/凸轮计算、可停止的独立优化器、固定理论凸轮的参数试调、MAT 保存与候选点集导出。

点击“固定凸轮反推”，再修改轮径、实际传动比、c、中心距、轴距或传感器位置，点击“更新反推”查看路线变化。此时不重新设计凸轮；退出后恢复原设计。它是理想运动学调参工具，尚不包含实际轮廓接触、间隙和轮胎滑移。

未完成原版逐点等价验证、原版高阶贝塞尔与 12 项评分公式、斜推/顶球、实际轮廓接触反推、车体碰撞检测和实体 CAD 建模。不要把本版本结果直接作为加工批准。

默认示例 15 轮优化的最大几何打卡偏差约 4.27 mm，但最大压力角约 63.25°，超过默认 35°；程序会显示此问题。该示例用于验证流程，不是已合格的参赛设计。
